# 05 转录组与RNA机制

[知识导航](../index.md) · [基因组、染色质、RNA与调控](../../docs/molecular-regulation.md) · [数据对象](../../data-formats/index.md)

RNA技术的区别首先在于测量变量：总量、异构体、端点、序列改变、合成与降解、翻译、蛋白接触、化学修饰和配对结构。它们不是同一表达矩阵的不同画法。下列编号沿用原索引；合并条目内明确区分不同任务，工具仅为实现例子。

<a id="m035"></a>
## M035 bulk RNA-seq定量与差异表达

| 项目 | 内容 |
| --- | --- |
| 生物学问题与目的 | 样本平均RNA丰度是否改变，涉及哪些基因和转录程序？ |
| 基本原理 | 将RNA片段定量为基因或转录本特征；计数模型区分样本尺度、条件效应和变异。基因计数差异的一类模型采用负二项分布。 |
| 输入数据 / 上游实验 | RNA-seq FASTQ，或已生成的gene counts；样本设计、参考序列与注释。两种入口代表不同起始阶段。 |
| 核心处理 | 读段和样本质量检查；比对或转录本定量；特征汇总；过滤；归一化；按设计矩阵和contrast比较。 |
| 可以得到的结果 | 表达矩阵、log2 fold change、标准误或区间、P值和FDR；再用基因集分析概括功能。 |
| 分析意义与边界 | RNA量变化不是蛋白量或活性变化；组织细胞组成可能驱动平均差异；技术尺度归一化不等于绝对分子校准。 |
| 常用术语 | counts：计数；TPM：长度和样本尺度调整后的相对丰度；dispersion：离散度；contrast：待检验对比。 |
| 实现例子 | STAR、Salmon、DESeq2、edgeR、limma-voom；各实现的输入要求和模型不同，不能把logTPM直接作为DESeq2原始计数。 |
| 直接来源 | [DESeq2模型与输入](../../references/index.md#deseq)；[RNA预处理流程](../../references/index.md#rnaseq)。 |

## M036 异构体与长读长转录组

| 项目 | 内容 |
| --- | --- |
| 生物学问题与目的 | 一个基因产生了哪些转录本，外显子怎样组合，各异构体使用多少？ |
| 基本原理 | 长RNA读段跨越多个剪接连接，以内含子链或图结构约束转录本路径，再进行读段归属和定量。 |
| 输入数据 / 上游实验 | PacBio或ONT的cDNA/直接RNA读段；参考基因组，可选转录本注释及条码归属。 |
| 核心处理 | 剪接比对；处理测序和边界误差；转录本重建与合并；注释匹配；读段归属；定量与结构检查。 |
| 可以得到的结果 | 转录本结构、已知/新异构体候选、基因与转录本丰度。 |
| 分析意义与边界 | 基因总量相同仍可存在不同异构体；长读段不保证每条都是完整无误差转录本；截短、内部引物和比对错误可形成假候选。 |
| 常用术语 | isoform：异构体；intron chain：内含子链；FSM：完全剪接匹配；collapse：合并冗余转录本。 |
| 实现例子 | IsoQuant、FLAIR、TALON、SQANTI3；分别承担重建、定量或结构质量检查等任务。 |
| 直接来源 | [IsoQuant原始研究与输入输出](../../references/nature-papers.md#n02)。 |

## M037 可变剪接与差异转录本使用

| 项目 | 内容 |
| --- | --- |
| 生物学问题与目的 | 条件变化是否影响RNA的加工选择，而不只是总表达？ |
| 基本原理 | 事件分析比较外显子或剪接连接的包含/排除；差异转录本使用比较同一基因内部的转录本比例。两者的特征定义不同。 |
| 输入数据 / 上游实验 | RNA比对、junction/事件计数，或转录本定量；生物重复和实验设计。 |
| 核心处理 | 定义事件或转录本集合；估计使用比例；考虑测序覆盖和样本间变异；检验使用变化。 |
| 可以得到的结果 | 剪接事件、PSI、ΔPSI，或差异转录本使用结果及不确定性。 |
| 分析意义与边界 | 总表达差异与使用比例差异可以独立发生；事件分析不一定唯一重建完整异构体；不能把合并重复后测得的覆盖当成生物学变异。 |
| 常用术语 | PSI：包含比例；DTU：差异转录本使用；IR：内含子保留；junction：剪接连接。 |
| 实现例子 | rMATS、LeafCutter、DEXSeq、DRIMSeq；对应的事件、外显子或转录本层级应分别理解。 |
| 直接来源 | [rMATS：重复样本中的差异剪接](../../references/index.md#rmats)；转录本重建见[M036](#m036)。 |

## M038 APA与转录起始位点分析

| 项目 | 内容 |
| --- | --- |
| 生物学问题与目的 | RNA从哪里开始、在哪里结束，启动子和3′端使用是否改变？ |
| 基本原理 | APA分析3′端切割加尾位点的选择；TSS分析5′端转录起始的分布。它们是两种不同任务，不应使用同一端点解释。 |
| 输入数据 / 上游实验 | APA使用专门3′端读出或相应RNA覆盖；TSS使用CAGE/RAMPAGE等起始端读出；长读长可补充端点组合。 |
| 核心处理 | 端点定位与聚类；背景及内部引物等检查；定量位点使用；比较条件。 |
| 可以得到的结果 | 候选加尾位点、3′UTR长短与比例；或TSS簇、启动子使用及其变化。 |
| 分析意义与边界 | 端点改变可以影响调控语境；常规覆盖推断、3′单细胞计数和专用端点实验的分辨力不同；UTR缩短不自动意味着蛋白增加。 |
| 常用术语 | APA：可变多聚腺苷化；TSS：转录起始位点；UTR：非翻译区；CTSS：CAGE识别的TSS。 |
| 实现例子 | DaPars、QAPA用于APA相关任务；CAGEr用于CAGE/TSS分析。 |
| 直接来源 | [DaPars原始研究](https://www.nature.com/articles/ncomms6274)；[CAGEr原始方法](https://pubmed.ncbi.nlm.nih.gov/25653163/)；[UTR与蛋白量的实测比较](https://pubmed.ncbi.nlm.nih.gov/25413384/)。 |

## M039 融合转录本与RNA编辑

| 项目 | 内容 |
| --- | --- |
| 生物学问题与目的 | RNA是否包含异常跨基因连接，或与对应DNA不同的加工后碱基？ |
| 基本原理 | 融合检测寻找跨基因的连接和成对支持；RNA编辑检测分析RNA-DNA差异并排除遗传变异和技术错误。两者不是相同的分子过程。 |
| 输入数据 / 上游实验 | RNA reads/比对；参考与注释；编辑分析可结合匹配DNA和变异信息。 |
| 核心处理 | 融合：嵌合比对、断点证据、伪基因与read-through检查。编辑：碱基质量、链向、覆盖、比对及DNA变异过滤。 |
| 可以得到的结果 | 融合候选、断点与支持读段；或编辑候选位点、碱基变化与比例。 |
| 分析意义与边界 | RNA中的融合信号不单独证明基因组重排；A-to-I常在测序中表现为A-to-G差异，但不是所有A/G差异都来自编辑。 |
| 常用术语 | fusion：融合；chimeric read：嵌合读段；read-through：跨相邻基因的读穿；A-to-I：腺苷到肌苷编辑。 |
| 实现例子 | Arriba、STAR-Fusion用于融合；REDItools用于编辑。 |
| 直接来源 | [Arriba原始方法](https://pubmed.ncbi.nlm.nih.gov/33441414/)；[REDItools原始方法](https://pubmed.ncbi.nlm.nih.gov/23742983/)及[过滤与数据说明](https://pubmed.ncbi.nlm.nih.gov/25754992/)。 |

## M040 小RNA与非编码RNA分析

| 项目 | 内容 |
| --- | --- |
| 生物学问题与目的 | 存在哪些小RNA家族，其产生与丰度怎样变化？ |
| 基本原理 | 联合读段长度、序列、基因组位置及特定生物发生特征进行注释和定量；miRNA候选还可结合前体结构与成熟片段分布。 |
| 输入数据 / 上游实验 | small RNA-seq及相应接头、长度和参考注释；不同小RNA类别可能需要不同建库或识别方法。 |
| 核心处理 | 接头和长度处理；多重比对；类别或位点归属；候选发现；表达比较。 |
| 可以得到的结果 | 小RNA丰度、家族与异构体组成、新miRNA候选等。 |
| 分析意义与边界 | 不同类别不能只按长度混成同一分析对象；多拷贝与修饰可影响识别；小RNA靶点预测不等于直接验证调控。 |
| 常用术语 | miRNA：微RNA；isomiR：miRNA序列变体；piRNA：PIWI相关RNA；tRF：tRNA来源片段。 |
| 实现例子 | miRDeep2是miRNA识别的代表，不是所有非编码RNA的统一分析器；其他类别需专用方法。 |
| 直接来源 | [miRDeep2原始研究，Nucleic Acids Research，2012（2011在线发表）](https://pubmed.ncbi.nlm.nih.gov/21911355/)。该文支持miRNA部分，不涵盖全部小RNA类别。 |

## M041 新生转录与RNA合成/降解动力学

| 项目 | 内容 |
| --- | --- |
| 生物学问题与目的 | RNA量变化来自合成、加工还是降解？转录是否在特定位置暂停？ |
| 基本原理 | 新生转录方法观察延伸相关RNA；代谢标记区分新旧RNA，并结合时间和观测模型估计速率。 |
| 输入数据 / 上游实验 | PRO/GRO/NET-seq等新生RNA数据，或TT/SLAM-seq等标记读出；实验时间、条件及标记信息。 |
| 核心处理 | 与实验匹配的比对和链向分析；识别标记/转换或聚合酶位置；定量并拟合动态模型。 |
| 可以得到的结果 | 新生转录信号、暂停相关指标，或模型约束下的合成、降解和半衰期估计。 |
| 分析意义与边界 | 静态RNA量一般无法同时识别合成与降解；标记效率、时间窗口及稳态假设影响估计；不同实验输出并非彼此可直接替换。 |
| 常用术语 | nascent RNA：新生RNA；pulse/chase：脉冲/追踪；half-life：半衰期；pause index：暂停相关比值。 |
| 实现例子 | GR​AND-SLAM及各新生RNA专用流程；首先按实验选择观测模型，而不是统一套用常规表达计数流程。 |
| 直接来源 | [SLAM-seq原始研究](../../references/index.md#slam)；[动力学模型基础](../../references/index.md#copasi)。SLAM-seq文献不替代所有PRO/GRO/NET-seq实验的专门来源。 |

## M042 核糖体测序Ribo-seq

| 项目 | 内容 |
| --- | --- |
| 生物学问题与目的 | 哪些RNA区域被核糖体占据，哪些阅读框具有翻译证据？ |
| 基本原理 | 定量核糖体保护的RNA片段，利用片段位置与阅读框周期性分析翻译。 |
| 输入数据 / 上游实验 | RPF reads、注释；比较相对翻译信息时常结合匹配RNA-seq。 |
| 核心处理 | 污染与片段质量检查；比对；P-site定位；周期性、ORF和相对占据分析。 |
| 可以得到的结果 | 核糖体占据轨道、翻译ORF候选、与RNA量相比的相对翻译信息。 |
| 分析意义与边界 | 占据同时受起始、停顿和延伸影响，不是蛋白稳态量；简单的RPF/RNA比例还需要合适的统计设计。 |
| 常用术语 | RPF：核糖体保护片段；P-site：肽酰位点；ORF：开放阅读框；TE：特定分析定义下的翻译效率。 |
| 实现例子 | RiboTISH、RiboCode、nf-core/riboseq。 |
| 实现来源 | [nf-core/riboseq文档](../../references/index.md#ribo)。 |

## M043 CLIP/eCLIP/iCLIP与RBP结合

| 项目 | 内容 |
| --- | --- |
| 生物学问题与目的 | 哪些RNA区域与指定RNA结合蛋白接触？ |
| 基本原理 | 交联并富集RBP所接触的RNA，通过读段分布、截断或其他交联相关特征定位接触。 |
| 输入数据 / 上游实验 | CLIP reads、匹配背景/输入对照、样本及条码信息。 |
| 核心处理 | 质量和分子副本处理；交联位点或峰识别；RNA丰度及背景控制；位置和序列偏好分析。 |
| 可以得到的结果 | 接触相关区域或位点、靶RNA候选、位置和motif偏好。 |
| 分析意义与边界 | 接触证据不单独证明对该RNA产生功能调控；交联效率、抗体和RNA丰度改变富集信号；不同CLIP方法分辨率不同。 |
| 常用术语 | RBP：RNA结合蛋白；crosslink：交联；input：输入对照；enrichment：富集。 |
| 实现例子 | CLIPper、PureCLIP及各协议匹配的流程。 |
| 直接来源 | [eCLIP原始研究](../../references/index.md#eclip)；[motif实现](../../references/index.md#meme)。 |

## M044 RNA修饰与表观转录组

| 项目 | 内容 |
| --- | --- |
| 生物学问题与目的 | RNA的哪些位置带有化学修饰，在给定条件下有多少分子被修饰？ |
| 基本原理 | 抗体富集、选择性化学/酶反应或直接RNA信号提供不同的修饰证据；从区域富集到单碱基定量并非同一测量。 |
| 输入数据 / 上游实验 | MeRIP等富集/输入数据，或单碱基化学读出、直接RNA信号；需要相应对照、覆盖和校准。 |
| 核心处理 | 背景和表达控制；峰或位点识别；错误/转换率评估；修饰比例估计与条件比较。 |
| 可以得到的结果 | 修饰候选区域或位点；某些定量实验可得到位点修饰比例，而非所有方法均可。 |
| 分析意义与边界 | 抗体富集峰通常不能直接给出单碱基位置或绝对占比；定量方法仍依赖化学效率、覆盖和观测模型。 |
| 常用术语 | m6A：N6-甲基腺苷；stoichiometry：修饰占比；conversion：化学转换；peak：富集区域。 |
| 实现例子 | 富集峰分析、GLORI对应分析、直接RNA修饰模型是不同分支，不能将其结果字段无条件合并。 |
| 直接来源 | [GLORI原始研究（2022在线，2023卷期）](https://www.nature.com/articles/s41587-022-01487-9)；[GLORI改进研究，Nature Methods，2025](https://www.nature.com/articles/s41592-025-02680-9)。此处使用公开摘要中的测量原理与适用范围，不声称核验全部补充方法。 |

## M045 RNA二级结构与互作结构

| 项目 | 内容 |
| --- | --- |
| 生物学问题与目的 | RNA哪些位置具有配对或暴露特征，哪些片段在分子内或分子间相互作用？ |
| 基本原理 | DMS/SHAPE等化学反应性为结构模型增加约束；交联与连接类方法记录特定近邻或配对片段；纯序列折叠则依赖能量或学习模型。 |
| 输入数据 / 上游实验 | RNA序列；化学探测处理/对照reads；或PARIS/SPLASH等互作相关连接数据。 |
| 核心处理 | 估计反应性及误差；约束结构预测；识别连接片段和互作候选；比较状态。 |
| 可以得到的结果 | 反应性轨道、兼容二级结构或配对概率、分子内/分子间互作候选。 |
| 分析意义与边界 | 反应性不是原子坐标；一个最小能量结构不代表全部构象；化学可及性也受蛋白结合和条件影响。 |
| 常用术语 | SHAPE：选择性2′羟基酰化及相关分析；DMS：二甲基硫酸；MFE：最小自由能；duplex：双链配对。 |
| 实现例子 | RNAstructure、ViennaRNA及实验匹配的反应性/连接分析流程。 |
| 直接来源 | [DMS-MaPseq原始研究](../../references/index.md#dms)；[SPLASH原始研究，Molecular Cell，2016](https://pubmed.ncbi.nlm.nih.gov/27184079/)。两者分别支持化学结构约束与RNA互作读出。 |
