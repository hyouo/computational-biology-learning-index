# 04 群体遗传与因果优先级

[返回领域导航](../index.md) · [学习方式](../../docs/learning-guide.md)

以下为方法家族的初始学习卡片；代表工具不是排名，模型输出需结合适用假设和实验设计解读。

<a id="m027"></a>
## M027 GWAS与表型组关联PheWAS

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 方向核心 |
| 处理目的 | 定位性状相关位点及共享表型 |
| 基本原理 | 逐位点或逐表型回归，并校正群体结构和亲缘 |
| 输入数据 / 上游实验 | 基因型/剂量；表型；协变量；祖源/亲缘 |
| 核心处理 | QC；PCA；混合模型关联；多重检验；复制 |
| 可以得到的结果 | 效应及P值、Manhattan/QQ图、关联位点 |
| 常用术语 | GWAS：全基因组关联；LD：连锁不平衡；MAF：次要等位频率 |
| 代表工具 | PLINK；REGENIE；SAIGE |
| 前提、QC与证据边界 | 关联位点不等于因果变异；最近基因不一定为效应基因 |
| 代表来源与延伸阅读 | [plink](../../references/index.md#plink) · [susie](../../references/index.md#susie) |


<a id="m028"></a>
## M028 分子QTL：eQTL/sQTL/pQTL等

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 方向核心 |
| 处理目的 | 连接遗传位点和潜在分子机制 |
| 基本原理 | 将遗传变异与表达、剪接、蛋白等分子表型关联 |
| 输入数据 / 上游实验 | 基因型；匹配分子矩阵；组织/批次协变量 |
| 核心处理 | cis/trans扫描；协变量调整；置换/校正 |
| 可以得到的结果 | QTL及效应方向、组织/细胞类型特异关联 |
| 常用术语 | cis/trans-QTL：局部/远端关联；sQTL：剪接QTL |
| 代表工具 | tensorQTL；QTLtools；FastQTL |
| 前提、QC与证据边界 | 细胞组成与组织背景很关键；跨组织转用需谨慎 |
| 代表来源与延伸阅读 | [coloc](../../references/index.md#coloc) · [plink](../../references/index.md#plink) |


<a id="m029"></a>
## M029 稀有变异负荷与基因水平检验

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 进阶专题 |
| 处理目的 | 提高罕见功能变异与表型关联的检出力 |
| 基本原理 | 在基因内聚合低频变异，或建模多变异方差分量 |
| 输入数据 / 上游实验 | WES/WGS变异；功能注释；表型 |
| 核心处理 | 定义mask；burden/SKAT类检验；多重校正 |
| 可以得到的结果 | 基因级关联、功能类别分层结果 |
| 常用术语 | burden：负荷；mask：变异集合；LoF：功能丧失 |
| 代表工具 | SAIGE-GENE；REGENIE；SKAT |
| 前提、QC与证据边界 | 不同变异方向和功能不相同；mask选择改变功效和结论 |
| 代表来源与延伸阅读 | [sarek](../../references/index.md#sarek) · [plink](../../references/index.md#plink) · [stats](../../references/index.md#stats) |


<a id="m030"></a>
## M030 遗传精细定位

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 方向核心 |
| 处理目的 | 缩小候选因果变异集合 |
| 基本原理 | 在LD相关变异中分配因果模型后验权重 |
| 输入数据 / 上游实验 | 区域GWAS统计量；匹配LD；可选功能先验 |
| 核心处理 | 稀疏贝叶斯回归；多信号分解；敏感性检查 |
| 可以得到的结果 | PIP、可信集合及独立信号 |
| 常用术语 | PIP：后验纳入概率；credible set：可信集合 |
| 代表工具 | SuSiE；FINEMAP |
| 前提、QC与证据边界 | 可信集合取决于LD、模型和先验；PIP不是实验确证 |
| 代表来源与延伸阅读 | [susie](../../references/index.md#susie) |


<a id="m031"></a>
## M031 遗传共定位

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 方向核心 |
| 处理目的 | 判断GWAS与QTL是否可能共享来源 |
| 基本原理 | 比较两个性状区域信号是否兼容共享因果变异 |
| 输入数据 / 上游实验 | 两性状区域统计量；等位基因；可选LD |
| 核心处理 | 对齐；多信号分解；后验假设比较 |
| 可以得到的结果 | 共享/独立信号的后验支持 |
| 常用术语 | colocalization：共定位；PP.H4：共享因果假设后验 |
| 代表工具 | coloc；coloc-SuSiE |
| 前提、QC与证据边界 | 共享位点不直接证明分子表型介导疾病；先验和多信号影响结果 |
| 代表来源与延伸阅读 | [coloc](../../references/index.md#coloc) · [susie](../../references/index.md#susie) |


<a id="m032"></a>
## M032 孟德尔随机化MR

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 进阶专题 |
| 处理目的 | 为潜在暴露/靶点因果关系提供证据 |
| 基本原理 | 在工具变量假设下用遗传预测的暴露差异估计结局效应 |
| 输入数据 / 上游实验 | 暴露及结局GWAS；独立工具SNP |
| 核心处理 | 等位对齐；IVW等估计；多效性/异质性/方向敏感性 |
| 可以得到的结果 | 因果效应估计及稳健性证据 |
| 常用术语 | IV：工具变量；pleiotropy：多效性；weak instrument：弱工具 |
| 代表工具 | TwoSampleMR；MendelianRandomization |
| 前提、QC与证据边界 | 相关性、独立性、排除限制缺一不可；显著MR仍依赖假设 |
| 代表来源与延伸阅读 | [mr](../../references/index.md#mr) · [coloc](../../references/index.md#coloc) |


<a id="m033"></a>
## M033 多基因风险与遗传预测PRS

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 进阶专题 |
| 处理目的 | 风险分层、遗传预测与泛化研究 |
| 基本原理 | 用大量变异效应加权构建个体评分 |
| 输入数据 / 上游实验 | 目标基因型；训练GWAS；LD参考 |
| 核心处理 | 权重训练/收缩；独立验证；祖源和校准评估 |
| 可以得到的结果 | PRS、预测性能、分层相对风险 |
| 常用术语 | PRS/PGS：多基因评分；portability：可迁移性 |
| 代表工具 | PRSice；LDpred2；PRS-CS |
| 前提、QC与证据边界 | 不同祖源可失效；个人评分不是确定发病结论 |
| 代表来源与延伸阅读 | [plink](../../references/index.md#plink) · [sklearn](../../references/index.md#sklearn) |


<a id="m034"></a>
## M034 TWAS与遗传相关分析

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 进阶专题 |
| 处理目的 | 连接组织、基因与性状共性 |
| 基本原理 | 用遗传预测表达关联性状，或用LD结构估计共享遗传成分 |
| 输入数据 / 上游实验 | GWAS统计量；表达预测权重；LD参考 |
| 核心处理 | TWAS；条件分析；LDSC等；与精细定位/共定位联合 |
| 可以得到的结果 | 基因关联、遗传力或遗传相关系数 |
| 常用术语 | TWAS：转录组关联；h²：遗传力；rg：遗传相关 |
| 代表工具 | S-PrediXcan；FUSION；LDSC |
| 前提、QC与证据边界 | TWAS命中不等于表达介导；遗传相关不等于因果 |
| 代表来源与延伸阅读 | [coloc](../../references/index.md#coloc) · [plink](../../references/index.md#plink) · [mr](../../references/index.md#mr) |
