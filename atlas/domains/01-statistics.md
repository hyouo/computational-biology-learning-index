# 01 统计与研究设计

[返回领域导航](../index.md) · [学习方式](../../docs/learning-guide.md)

以下为方法家族的初始学习卡片；代表工具不是排名，模型输出需结合适用假设和实验设计解读。

<a id="m001"></a>
## M001 实验设计与功效分析

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 共同基础 |
| 处理目的 | 决定可回答的问题、样本量与对照结构 |
| 基本原理 | 用随机化、分层和重复区分处理效应与随机变异 |
| 输入数据 / 上游实验 | 生物学问题、实验单位、效应及方差预估 |
| 核心处理 | 定义主要终点；模拟或计算功效；安排随机化和盲法 |
| 可以得到的结果 | 设计方案、功效曲线、最小可检测效应 |
| 常用术语 | power：检出功效；biological replicate：独立生物重复 |
| 代表工具 | R；statsmodels；模拟代码 |
| 前提、QC与证据边界 | 细胞、视野、reads通常不能代替独立个体；功效依赖效应假设 |
| 代表来源与延伸阅读 | [stats](../../references/index.md#stats) · [deseq](../../references/index.md#deseq) |


<a id="m002"></a>
## M002 线性模型与广义线性模型

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 共同基础 |
| 处理目的 | 估计组别、剂量及交互效应 |
| 基本原理 | 以协变量解释响应均值；按数据选择高斯、二项或计数分布 |
| 输入数据 / 上游实验 | 样本×特征矩阵；分组与协变量 |
| 核心处理 | 设计矩阵；拟合；对比；残差诊断 |
| 可以得到的结果 | 效应估计、标准误、置信区间、检验结果 |
| 常用术语 | GLM：广义线性模型；link：连接函数；contrast：对比 |
| 代表工具 | R lm/glm；statsmodels |
| 前提、QC与证据边界 | 不能用加入协变量自动解决所有混杂；模型分布需符合数据 |
| 代表来源与延伸阅读 | [stats](../../references/index.md#stats) · [deseq](../../references/index.md#deseq) |


<a id="m003"></a>
## M003 混合效应与层级模型

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 共同基础 |
| 处理目的 | 分析重复测量、多中心、同个体多细胞或多视野 |
| 基本原理 | 同时估计总体效应和个体、批次等层级变异 |
| 输入数据 / 上游实验 | 观测值；个体/实验批次ID；时间与分组 |
| 核心处理 | 设置固定与随机效应；检查收敛及层级结构 |
| 可以得到的结果 | 总体效应、个体差异、方差分量 |
| 常用术语 | LMM/GLMM：混合模型；ICC：组内相关 |
| 代表工具 | lme4；glmmTMB；statsmodels |
| 前提、QC与证据边界 | 层级很少时方差难估；不可把相关观测当独立样本 |
| 代表来源与延伸阅读 | [stats](../../references/index.md#stats) · [muscat](../../references/index.md#muscat) |


<a id="m004"></a>
## M004 多重检验与效应量

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 共同基础 |
| 处理目的 | 避免把偶然显著结果当作生物发现 |
| 基本原理 | 在大量假设中控制错误发现比例，并报告变化大小 |
| 输入数据 / 上游实验 | P值、效应估计、置信区间 |
| 核心处理 | 预定义检验家族；BH等校正；效应阈值与敏感性检查 |
| 可以得到的结果 | FDR调整值、效应排序、可靠候选集 |
| 常用术语 | FDR：错误发现率；CI：置信区间；log2FC：变化倍数对数 |
| 代表工具 | p.adjust；DESeq2；statsmodels |
| 前提、QC与证据边界 | FDR不是某单个基因是假阳性的概率；不显著不等于没有效应 |
| 代表来源与延伸阅读 | [deseq](../../references/index.md#deseq) · [stats](../../references/index.md#stats) |


<a id="m005"></a>
## M005 置换、Bootstrap与非参数检验

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 共同基础 |
| 处理目的 | 减少对分布形式的依赖 |
| 基本原理 | 重排标签或重采样构造零分布与不确定性 |
| 输入数据 / 上游实验 | 原始样本、层级和分组标签 |
| 核心处理 | 在正确实验单位内重采样；保留配对或区组 |
| 可以得到的结果 | 经验P值、置信区间、稳定性评估 |
| 常用术语 | permutation：置换；bootstrap：自助法；exchangeability：可交换性 |
| 代表工具 | R；SciPy；statsmodels |
| 前提、QC与证据边界 | 不能随意打散患者内部细胞或空间相关样本 |
| 代表来源与延伸阅读 | [stats](../../references/index.md#stats) · [sklearn](../../references/index.md#sklearn) |


<a id="m006"></a>
## M006 归一化与组成性数据分析

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 共同基础 |
| 处理目的 | 比较不同测序深度、样本总量和组成 |
| 基本原理 | 校正测量规模或在相对比例空间建模 |
| 输入数据 / 上游实验 | counts、总量、内标、样本元数据 |
| 核心处理 | size factor/TMM；log-ratio；合适内标校准 |
| 可以得到的结果 | 可比较的相对信号或经校准的绝对量 |
| 常用术语 | offset：规模项；CLR/ALR：对数比变换；compositionality：组成性 |
| 代表工具 | DESeq2；edgeR；QIIME 2 |
| 前提、QC与证据边界 | 总量固定会引入伪负相关；相对升高不一定绝对升高 |
| 代表来源与延伸阅读 | [deseq](../../references/index.md#deseq) · [qiime](../../references/index.md#qiime) |


<a id="m007"></a>
## M007 缺失数据、删失与插补

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 共同基础 |
| 处理目的 | 减少缺失机制引入的偏差 |
| 基本原理 | 显式区分未测到、随机缺失、检测限和事件未发生 |
| 输入数据 / 上游实验 | 含缺失的数据；检测限；随访信息 |
| 核心处理 | 检查MCAR/MAR/MNAR；适当插补或删失模型；敏感性分析 |
| 可以得到的结果 | 完整分析集、估计值与缺失机制敏感性 |
| 常用术语 | MCAR/MAR/MNAR：三类缺失机制；censoring：删失 |
| 代表工具 | mice；statsmodels；领域专用模型 |
| 前提、QC与证据边界 | 低丰度未检出不能一概补零；插补不能创造独立证据 |
| 代表来源与延伸阅读 | [stats](../../references/index.md#stats) · [maxquant](../../references/index.md#maxquant) · [msdial](../../references/index.md#msdial) |


<a id="m008"></a>
## M008 生存与纵向数据分析

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 方向核心 |
| 处理目的 | 比较风险、复发、发育或长期变化 |
| 基本原理 | 对事件时间及随时间变化的响应建模 |
| 输入数据 / 上游实验 | 随访时间、事件/删失、协变量、重复时间点 |
| 核心处理 | KM；Cox或参数模型；纵向混合模型；检验假设 |
| 可以得到的结果 | 生存曲线、风险比、时间趋势及区间 |
| 常用术语 | HR：风险比；PH：比例风险；censoring：删失 |
| 代表工具 | survival；lifelines；statsmodels |
| 前提、QC与证据边界 | HR比较瞬时风险，不等于累积风险比（risk ratio）或概率；需处理时间依赖偏差与失访 |
| 代表来源与延伸阅读 | [stats](../../references/index.md#stats) |


<a id="m009"></a>
## M009 因果图、倾向评分与目标试验思维

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 进阶专题 |
| 处理目的 | 观察数据中尽量接近明确定义的因果问题 |
| 基本原理 | 用因果假设识别应调整变量和可估计的干预效应 |
| 输入数据 / 上游实验 | 处理、结局、处理前协变量、纳入规则与时间零点 |
| 核心处理 | DAG；匹配/加权；平衡检查；敏感性分析 |
| 可以得到的结果 | 明确目标估计量、ATE/ATT及不确定性 |
| 常用术语 | DAG：有向无环图；IPW：逆概率加权；collider：碰撞变量 |
| 代表工具 | DAGitty；WeightIt；DoWhy |
| 前提、QC与证据边界 | 不可检验的无未测混杂等假设仍在；不能调整所有变量了事 |
| 代表来源与延伸阅读 | [stats](../../references/index.md#stats) · [mr](../../references/index.md#mr) |


<a id="m010"></a>
## M010 Meta分析与跨队列复现

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 方向核心 |
| 处理目的 | 评估跨实验、群体和平台的稳定性 |
| 基本原理 | 按研究精度和异质性合并效应，而非合并显著性 |
| 输入数据 / 上游实验 | 各研究效应、标准误、设计与人群信息 |
| 核心处理 | 方向统一；固定/随机效应；异质性和发表偏倚分析 |
| 可以得到的结果 | 汇总效应、森林图、异质性和敏感性结果 |
| 常用术语 | I²：异质性指标；random effects：随机效应 |
| 代表工具 | metafor；meta；statsmodels |
| 前提、QC与证据边界 | 不相同终点、平台及人群不能机械合并；选择性发表可偏倚 |
| 代表来源与延伸阅读 | [stats](../../references/index.md#stats) |
