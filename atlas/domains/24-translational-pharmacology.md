# 24 转化研究与药理数据

[返回领域导航](../index.md) · [学习方式](../../docs/learning-guide.md)

以下为方法家族的初始学习卡片；代表工具不是排名，模型输出需结合适用假设和实验设计解读。

<a id="m183"></a>
## M183 剂量—反应与药效曲线

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 方向核心 |
| 处理目的 | 比较效力、最大效应和作用窗口 |
| 基本原理 | 用饱和/抑制模型连接剂量与实验响应 |
| 输入数据 / 上游实验 | 多剂量多重复读出、对照、浓度单位与时间 |
| 核心处理 | 4PL/Hill拟合；背景/归一；曲线QC；区间估计 |
| 可以得到的结果 | IC50/EC50、Emax、Hill系数与误差 |
| 常用术语 | IC50/EC50：半抑制/半效浓度；Emax：最大效应 |
| 代表工具 | drc；GraphPad Prism；SciPy；COPASI |
| 前提、QC与证据边界 | IC50依赖实验条件不是固有Kd；未达到平台的曲线参数不可靠 |
| 代表来源与延伸阅读 | [copasi](../../references/index.md#copasi) · [stats](../../references/index.md#stats) |


<a id="m184"></a>
## M184 药物组合与协同评分

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 进阶专题 |
| 处理目的 | 筛选协同/拮抗组合并解释条件依赖 |
| 基本原理 | 相对指定无互作基线比较组合响应 |
| 输入数据 / 上游实验 | 二维剂量矩阵、单药曲线、重复、读出时间 |
| 核心处理 | Bliss/Loewe/HSA/ZIP零模型；响应面；不确定性 |
| 可以得到的结果 | 协同地图、剂量窗口及候选组合 |
| 常用术语 | Bliss/Loewe：不同无互作定义；response surface：响应面 |
| 代表工具 | SynergyFinder；Combenefit；自定义模型 |
| 前提、QC与证据边界 | 不同零模型可能给不同结论；细胞系协同不保证体内疗效 |
| 代表来源与延伸阅读 | [copasi](../../references/index.md#copasi) · [stats](../../references/index.md#stats) · [sklearn](../../references/index.md#sklearn) |


<a id="m185"></a>
## M185 PK/PD与生理药代模型

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 进阶专题 |
| 处理目的 | 连接剂量、暴露、靶点和响应 |
| 基本原理 | 用分室或生理结构描述浓度与效应随时间变化 |
| 输入数据 / 上游实验 | 血/组织浓度、剂量时间、个体协变量、效应 |
| 核心处理 | 分室/群体模型；参数拟合；诊断；情景模拟 |
| 可以得到的结果 | 清除/分布参数、暴露、效应曲线及变异 |
| 常用术语 | PK/PD：药代/药效；AUC：浓度时间曲线下面积；PBPK：生理药代 |
| 代表工具 | NONMEM；Monolix；mrgsolve；PK-Sim；COPASI |
| 前提、QC与证据边界 | 样本稀疏可不可辨识；物种和体外到体内外推有前提 |
| 代表来源与延伸阅读 | [copasi](../../references/index.md#copasi) · [stats](../../references/index.md#stats) |


<a id="m186"></a>
## M186 诊断/预后标志物建模

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 方向核心 |
| 处理目的 | 评估候选标志物的增量价值 |
| 基本原理 | 从临床与分子特征构建分类或风险模型 |
| 输入数据 / 上游实验 | 个体级组学、结局、协变量、独立验证集 |
| 核心处理 | 训练内特征选择；CV；外部验证；校准和决策曲线 |
| 可以得到的结果 | AUROC/AUPRC、敏感度/特异度、校准和净获益 |
| 常用术语 | PPV/NPV：阳性/阴性预测值；calibration：校准；C-index：一致性指数 |
| 代表工具 | scikit-learn；survival；rms；tidymodels |
| 前提、QC与证据边界 | 患病率影响预测值；不能把训练集显著性当临床实用性 |
| 代表来源与延伸阅读 | [sklearn](../../references/index.md#sklearn) · [stats](../../references/index.md#stats) |


<a id="m187"></a>
## M187 多中心队列、电子病历与真实世界证据

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 进阶专题 |
| 处理目的 | 复现关联、识别表型及估计治疗相关效应 |
| 基本原理 | 把异质记录转成可比较的表型和明确研究队列 |
| 输入数据 / 上游实验 | EHR、编码、实验室/用药/事件时间、纳排规则 |
| 核心处理 | 表型定义；时间对齐；缺失/混杂处理；跨中心验证 |
| 可以得到的结果 | 研究队列、发生率、关联或假设条件下的效应 |
| 常用术语 | EHR：电子健康记录；immortal time：不死时间；target trial：目标试验 |
| 代表工具 | OMOP/OHDSI生态；统计与因果工具 |
| 前提、QC与证据边界 | 记录缺失不代表事件未发生；选择偏倚、测量差异和时间零点非常关键 |
| 代表来源与延伸阅读 | [stats](../../references/index.md#stats) · [sklearn](../../references/index.md#sklearn) · [mr](../../references/index.md#mr) |


<a id="m188"></a>
## M188 类器官/动物模型与跨物种转译分析

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 方向核心 |
| 处理目的 | 连接机制实验、组织背景和转化假设 |
| 基本原理 | 用受控模型测量干预效应并比较人类相关性 |
| 输入数据 / 上游实验 | 类器官/动物多重复表型、组学、批次及人类参考 |
| 核心处理 | 混合模型；剂量/时间；细胞组成；同源映射；跨模型验证 |
| 可以得到的结果 | 模型内效应、保守/特异机制、外推限制 |
| 常用术语 | organoid：类器官；xenograft：异种移植；external validity：外部效度 |
| 代表工具 | 统计/单细胞/图像/同源分析流程 |
| 前提、QC与证据边界 | 模型内因果不自动等于人类病理机制；个体、培养批次和窝别是设计单位 |
| 代表来源与延伸阅读 | [stats](../../references/index.md#stats) · [muscat](../../references/index.md#muscat) · [iqtree](../../references/index.md#iqtree) |
