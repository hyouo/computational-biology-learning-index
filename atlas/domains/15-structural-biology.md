# 15 结构生物学与实验重建

[返回领域导航](../index.md) · [学习方式](../../docs/learning-guide.md)

以下为方法家族的初始学习卡片；代表工具不是排名，模型输出需结合适用假设和实验设计解读。

<a id="m112"></a>
## M112 冷冻电镜单颗粒重建

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 方向核心 |
| 处理目的 | 解析大分子或复合体结构 |
| 基本原理 | 从大量随机取向颗粒二维投影重建三维密度 |
| 输入数据 / 上游实验 | cryo-EM movies、显微参数、样本信息 |
| 核心处理 | 运动/CTF校正；挑粒；2D/3D分类；精修；map验证 |
| 可以得到的结果 | 三维密度、构象类别、分辨率和原子模型 |
| 常用术语 | CTF：对比度传递函数；FSC：傅里叶壳相关；half-map：半数据图 |
| 代表工具 | RELION；CryoSPARC；Phenix；Coot |
| 前提、QC与证据边界 | 过拟合、优选取向和异质性会影响局部分辨率；模型需与独立数据验证 |
| 代表来源与延伸阅读 | [cryo](../../references/index.md#cryo) · [relion](../../references/index.md#relion) · [phenix](../../references/index.md#phenix) |


<a id="m113"></a>
## M113 冷冻电镜断层与亚断层平均

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 进阶专题 |
| 处理目的 | 研究细胞原位大分子与超微结构 |
| 基本原理 | 重建倾转序列的三维体并平均相似亚体积 |
| 输入数据 / 上游实验 | 倾转movies/series、几何信息、可选标记 |
| 核心处理 | 运动/倾斜校正；重建；分割；颗粒定位与平均 |
| 可以得到的结果 | tomogram、原位位置、亚断层结构 |
| 常用术语 | cryo-ET：冷冻电镜断层；missing wedge：缺失楔；STA：亚断层平均 |
| 代表工具 | RELION；IMOD；AreTomo；Dynamo |
| 前提、QC与证据边界 | 缺失角与剂量限制带来各向异性；分割/挑粒可能有偏 |
| 代表来源与延伸阅读 | [relion](../../references/index.md#relion) · [cryo](../../references/index.md#cryo) |


<a id="m114"></a>
## M114 X射线晶体学

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 方向核心 |
| 处理目的 | 确定原子构象与配体结合模式 |
| 基本原理 | 从衍射强度和相位信息推断晶体电子密度 |
| 输入数据 / 上游实验 | 衍射图像、晶体参数、相位/同源模型 |
| 核心处理 | 索引积分；定标；相位/分子置换；建模精修；验证 |
| 可以得到的结果 | 电子密度、原子模型、Rwork/Rfree等 |
| 常用术语 | phase problem：相位问题；Rfree：留出反射误差；occupancy：占据率 |
| 代表工具 | DIALS；XDS；CCP4；Phenix；Coot |
| 前提、QC与证据边界 | 晶体接触可能限制构象；密度弱处不能过度精确解释 |
| 代表来源与延伸阅读 | [phenix](../../references/index.md#phenix) |


<a id="m115"></a>
## M115 核磁共振结构与动力学

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 进阶专题 |
| 处理目的 | 研究溶液构象、互作和动力学 |
| 基本原理 | 化学位移、NOE和弛豫等提供局部环境与距离/时间信息 |
| 输入数据 / 上游实验 | 多维NMR谱、序列、峰表与实验信息 |
| 核心处理 | 峰指认；约束生成；结构计算；弛豫/交换拟合 |
| 可以得到的结果 | 结构集合、残基动态、结合/交换参数 |
| 常用术语 | NOE：核Overhauser效应；chemical shift：化学位移；relaxation：弛豫 |
| 代表工具 | NMRPipe；CCPN；CYANA；Xplor-NIH |
| 前提、QC与证据边界 | 峰重叠和指认错误影响结构；结构集合不自动等于真实热力学分布 |
| 代表来源与延伸阅读 | [phenix](../../references/index.md#phenix) · [af3](../../references/index.md#af3) · [md](../../references/index.md#md) |


<a id="m116"></a>
## M116 SAXS/SANS与整合结构

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 进阶专题 |
| 处理目的 | 研究整体尺寸、柔性和复合体构型 |
| 基本原理 | 用低分辨率散射及多来源约束限制分子形状 |
| 输入数据 / 上游实验 | 散射曲线、浓度系列、结构及可选XL-MS/EM约束 |
| 核心处理 | 背景扣除；Rg/P(r)；形状/集合拟合；跨证据验证 |
| 可以得到的结果 | 整体形状、尺寸和兼容构象集合 |
| 常用术语 | Rg：回转半径；P(r)：距离分布；ensemble：构象集合 |
| 代表工具 | ATSAS；BioXTAS RAW；IMP |
| 前提、QC与证据边界 | 低分辨曲线通常不唯一确定原子结构；聚集和溶剂背景需排查 |
| 代表来源与延伸阅读 | [saxs](../../references/index.md#saxs) · [phenix](../../references/index.md#phenix) |


<a id="m117"></a>
## M117 蛋白/复合体结构预测

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 方向核心 |
| 处理目的 | 提供结构假设、界面和实验设计依据 |
| 基本原理 | 利用进化、序列模式和学习到的几何先验生成结构 |
| 输入数据 / 上游实验 | 蛋白/核酸序列、配体/离子等实体；可选MSA/模板 |
| 核心处理 | 输入整理；多种子/模型；置信度和界面检查 |
| 可以得到的结果 | 预测坐标、pLDDT、PAE、pTM/ipTM等 |
| 常用术语 | MSA：多序列比对；pLDDT：局部置信度；PAE：相对位置误差预测 |
| 代表工具 | AlphaFold；ColabFold；RoseTTAFold；其他结构模型 |
| 前提、QC与证据边界 | 高置信度≠实验验证；预测结构≠结合亲和力、细胞状态或完整动态 |
| 代表来源与延伸阅读 | [af3](../../references/index.md#af3) |


<a id="m118"></a>
## M118 结构比较、结构域与界面分析

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 方向核心 |
| 处理目的 | 比较家族、突变和潜在功能位点 |
| 基本原理 | 对齐三维坐标并计算几何、接触与保守性 |
| 输入数据 / 上游实验 | PDB/mmCIF结构、序列、置信度和注释 |
| 核心处理 | 结构对齐；domain识别；接触/界面面积；可视化 |
| 可以得到的结果 | RMSD/TM-score、结构相似候选、界面残基 |
| 常用术语 | RMSD：均方根偏差；TM-score：拓扑相似度；SASA：溶剂可及面积 |
| 代表工具 | TM-align；Foldseek；DALI；PyMOL；ChimeraX |
| 前提、QC与证据边界 | 全局相似不等于功能相同；低置信片段会误导比较 |
| 代表来源与延伸阅读 | [af3](../../references/index.md#af3) · [phenix](../../references/index.md#phenix) · [mdanalysis](../../references/index.md#mdanalysis) |


<a id="m119"></a>
## M119 构象异质性与连续结构景观

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 进阶专题 |
| 处理目的 | 研究柔性、运动与功能状态候选 |
| 基本原理 | 从颗粒或结构集合分解离散/连续构象变化 |
| 输入数据 / 上游实验 | 单颗粒图像、密度/结构集合、条件标签 |
| 核心处理 | 3D分类；变异分析；潜变量模型；交叉验证 |
| 可以得到的结果 | 构象类别、连续变化轴、占比估计 |
| 常用术语 | heterogeneity：异质性；conformational landscape：构象景观 |
| 代表工具 | cryoSPARC 3DVA；RELION；cryoDRGN |
| 前提、QC与证据边界 | 嵌入轴不是实际反应时间；不同构象占比可能受制样和挑粒偏倚 |
| 代表来源与延伸阅读 | [cryo](../../references/index.md#cryo) · [relion](../../references/index.md#relion) |
