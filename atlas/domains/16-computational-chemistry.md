# 16 计算化学、设计与药物分子

[返回领域导航](../index.md) · [学习方式](../../docs/learning-guide.md)

以下为方法家族的初始学习卡片；代表工具不是排名，模型输出需结合适用假设和实验设计解读。

<a id="m120"></a>
## M120 分子表示、指纹与化学空间

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 方向核心 |
| 处理目的 | 搜索相似物、构建化学特征和去重 |
| 基本原理 | 将分子表示为图、字符串、描述符或指纹 |
| 输入数据 / 上游实验 | SMILES/SDF、立体化学、性质或活性 |
| 核心处理 | 标准化；盐/互变异构体处理；描述符；相似/子结构搜索 |
| 可以得到的结果 | 分子特征、相似性、化学簇 |
| 常用术语 | SMILES：分子字符串；fingerprint：指纹；Tanimoto：相似度 |
| 代表工具 | RDKit；Open Babel |
| 前提、QC与证据边界 | 相同二维骨架不保证相同性能；质子化、互变异构体与手性重要 |
| 代表来源与延伸阅读 | [rdkit](../../references/index.md#rdkit) |


<a id="m121"></a>
## M121 分子对接与虚拟筛选

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 方向核心 |
| 处理目的 | 产生结合姿势及候选分子优先级 |
| 基本原理 | 搜索配体在靶标口袋的构象并用近似评分排序 |
| 输入数据 / 上游实验 | 受体结构、配体结构、口袋与质子化信息 |
| 核心处理 | 结构准备；构象搜索；打分；重对接/对照；复核 |
| 可以得到的结果 | 候选poses、评分、相互作用图 |
| 常用术语 | pose：结合姿势；docking score：对接评分；protonation：质子化 |
| 代表工具 | AutoDock Vina；Smina；Glide |
| 前提、QC与证据边界 | 对接分数不是实测Kd/IC50；水、柔性、金属和质子化可决定结果 |
| 代表来源与延伸阅读 | [vina](../../references/index.md#vina) · [rdkit](../../references/index.md#rdkit) |


<a id="m122"></a>
## M122 经典分子动力学MD

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 方向核心 |
| 处理目的 | 研究构象变化、局部柔性和分子环境 |
| 基本原理 | 用力场近似势能并积分运动方程 |
| 输入数据 / 上游实验 | 拓扑、初始坐标、力场、溶剂及条件 |
| 核心处理 | 能量最小化；平衡；多重复采样；轨迹收敛诊断 |
| 可以得到的结果 | 轨迹、接触/氢键、RMSF、构象分布 |
| 常用术语 | force field：力场；ensemble：系综；RMSF：波动；PBC：周期边界 |
| 代表工具 | GROMACS；AMBER；OpenMM；NAMD；MDAnalysis |
| 前提、QC与证据边界 | 有限时间/力场会限制采样；轨迹稳定不证明配体真能结合 |
| 代表来源与延伸阅读 | [md](../../references/index.md#md) · [mdanalysis](../../references/index.md#mdanalysis) |


<a id="m123"></a>
## M123 自由能计算与增强采样

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 进阶专题 |
| 处理目的 | 比较结合/突变效应、状态稳定性与转换 |
| 基本原理 | 改变体系或偏置采样跨越能垒以估计自由能差 |
| 输入数据 / 上游实验 | 分子体系、参考态、反应坐标和力场 |
| 核心处理 | FEP/TI；umbrella/metadynamics；重加权；重复及收敛 |
| 可以得到的结果 | ΔG/ΔΔG、PMF、误差和状态差异 |
| 常用术语 | FEP：自由能微扰；PMF：平均力势；collective variable：集体变量 |
| 代表工具 | GROMACS；PLUMED；OpenMM；alchemlyb |
| 前提、QC与证据边界 | 对状态定义和采样极敏感；MM/PBSA近似不能等同严格自由能 |
| 代表来源与延伸阅读 | [md](../../references/index.md#md) · [mdanalysis](../../references/index.md#mdanalysis) |


<a id="m124"></a>
## M124 QM、QM/MM与酶反应机制

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 进阶专题 |
| 处理目的 | 研究催化势垒、反应路径和电子效应 |
| 基本原理 | 用量子化学处理电子重排并与环境模型耦合 |
| 输入数据 / 上游实验 | 活性中心结构、质子化、电子态、环境模型 |
| 核心处理 | 量子区域选择；几何/过渡态；反应路径；环境采样 |
| 可以得到的结果 | 候选反应路径、能垒、电子结构 |
| 常用术语 | QM/MM：量子/分子力学；transition state：过渡态；DFT：密度泛函 |
| 代表工具 | ORCA；Gaussian；CP2K；QM/MM接口 |
| 前提、QC与证据边界 | 结果依赖电子结构近似、质子化和采样；不是仅靠一幅反应能图证明机制 |
| 代表来源与延伸阅读 | [md](../../references/index.md#md) · [copasi](../../references/index.md#copasi) |


<a id="m125"></a>
## M125 QSAR、ADMET与药物响应预测

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 进阶专题 |
| 处理目的 | 优先排序候选分子和响应标志物 |
| 基本原理 | 从结构或细胞分子特征学习活性、性质及响应 |
| 输入数据 / 上游实验 | 化学结构、实验活性、剂量/细胞系和实验条件 |
| 核心处理 | 数据清洗；scaffold/时间分割；建模；校准与外部验证 |
| 可以得到的结果 | 活性/性质预测、适用域、优先级 |
| 常用术语 | QSAR：定量构效关系；ADMET：吸收分布代谢排泄毒性；scaffold split：骨架分割 |
| 代表工具 | RDKit；Chemprop；scikit-learn；深度图模型 |
| 前提、QC与证据边界 | 不同测定条件不能盲目混合；预测ADMET不等于已证明体内安全有效 |
| 代表来源与延伸阅读 | [rdkit](../../references/index.md#rdkit) · [sklearn](../../references/index.md#sklearn) |


<a id="m126"></a>
## M126 蛋白逆折叠、扩散生成与设计评估

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 前沿选读 |
| 处理目的 | 提出新蛋白、结合分子和酶功能候选 |
| 基本原理 | 从结构设计序列，或按几何条件生成骨架/界面 |
| 输入数据 / 上游实验 | 骨架/功能约束、目标结构、序列/结构模型 |
| 核心处理 | 生成；逆折叠；结构回折验证；去同源偏倚；实验筛选 |
| 可以得到的结果 | 候选序列/骨架、预测成功指标及实验优先级 |
| 常用术语 | inverse folding：逆折叠；diffusion：扩散生成；designability：可设计性 |
| 代表工具 | ProteinMPNN；RFdiffusion；结构预测模型 |
| 前提、QC与证据边界 | 计算自洽不保证可溶、稳定、特异或有活性；必须实验闭环 |
| 代表来源与延伸阅读 | [rfdiff](../../references/index.md#rfdiff) · [af3](../../references/index.md#af3) · [sklearn](../../references/index.md#sklearn) |
