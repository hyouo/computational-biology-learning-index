# 14 代谢组、脂质组与通量

[返回领域导航](../index.md) · [学习方式](../../docs/learning-guide.md)

以下为方法家族的初始学习卡片；代表工具不是排名，模型输出需结合适用假设和实验设计解读。

<a id="m105"></a>
## M105 非靶向代谢组LC/GC-MS

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 方向核心 |
| 处理目的 | 发现代谢变化及未知候选物 |
| 基本原理 | 把色谱保留时间与质荷比分离的峰作为候选化学特征 |
| 输入数据 / 上游实验 | 原始质谱；空白/QC样本；批次和标准信息 |
| 核心处理 | 峰检测；去卷积；对齐；加合物/同位素归并；注释 |
| 可以得到的结果 | feature矩阵、候选代谢物及鉴定等级 |
| 常用术语 | m/z：质荷比；RT：保留时间；adduct：加合物；feature：峰特征 |
| 代表工具 | MS-DIAL；XCMS；MZmine |
| 前提、QC与证据边界 | 一个feature不等于一个代谢物；一个代谢物可产生多个峰 |
| 代表来源与延伸阅读 | [msdial](../../references/index.md#msdial) |


<a id="m106"></a>
## M106 靶向代谢组与定量NMR

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 方向核心 |
| 处理目的 | 精确比较浓度与验证通路变化 |
| 基本原理 | 针对已知化合物用标准曲线/内标或核磁信号定量 |
| 输入数据 / 上游实验 | 目标MS或NMR谱；标准品；内标及体积/质量 |
| 核心处理 | 校准；积分；回收/矩阵效应；定量范围评估 |
| 可以得到的结果 | 代谢物浓度、定量限和误差 |
| 常用术语 | IS：内标；matrix effect：基质效应；absolute quantification：绝对定量 |
| 代表工具 | Skyline；厂商软件；NMR定量软件 |
| 前提、QC与证据边界 | 非靶向相对峰面积不可直接当浓度；标准和样本基质需匹配 |
| 代表来源与延伸阅读 | [msdial](../../references/index.md#msdial) · [msstats](../../references/index.md#msstats) |


<a id="m107"></a>
## M107 脂质组学与分子种解析

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 进阶专题 |
| 处理目的 | 研究膜组成、脂质信号及代谢重塑 |
| 基本原理 | 按脂质类别、脂肪链及碎片规则注释信号 |
| 输入数据 / 上游实验 | LC-MS/MS、脂质标准和数据库 |
| 核心处理 | 分类搜索；链组成定位；内标归一；差异/通路分析 |
| 可以得到的结果 | 脂质类别与分子种丰度、候选结构 |
| 常用术语 | lipid species：脂质分子种；sum composition：总组成；sn-position：甘油位置 |
| 代表工具 | LipidSearch；MS-DIAL；LipidMatch |
| 前提、QC与证据边界 | 总碳数/双键数不能唯一确定位置异构体；不能超出鉴定层级命名 |
| 代表来源与延伸阅读 | [msdial](../../references/index.md#msdial) |


<a id="m108"></a>
## M108 稳定同位素示踪与代谢通量分析

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 进阶专题 |
| 处理目的 | 区分来源贡献、路径使用和代谢速率 |
| 基本原理 | 追踪标记原子进入代谢物的分布并拟合反应网络 |
| 输入数据 / 上游实验 | 13C/15N标记MS/NMR；时间；摄取/分泌速率；网络 |
| 核心处理 | 天然丰度校正；isotopologue分布；原子映射；MFA拟合 |
| 可以得到的结果 | 来源贡献、相对/绝对通量及置信区间 |
| 常用术语 | isotopologue：同位素体；MID：质量同位素分布；MFA：通量分析 |
| 代表工具 | INCA；13CFLUX2；Isodyn |
| 前提、QC与证据边界 | 标记比例不直接等于通量；稳态、池大小、网络与边界条件很重要 |
| 代表来源与延伸阅读 | [cobra](../../references/index.md#cobra) · [copasi](../../references/index.md#copasi) · [msdial](../../references/index.md#msdial) |


<a id="m109"></a>
## M109 代谢网络约束建模FBA/FVA

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 方向核心 |
| 处理目的 | 预测生长、交换需求和敲除效应 |
| 基本原理 | 以化学计量守恒和通量边界约束可行解空间 |
| 输入数据 / 上游实验 | 反应网络、化学计量矩阵、营养/交换上下界 |
| 核心处理 | 稳态S·v=0；选择目标；线性规划；通量范围/敲除 |
| 可以得到的结果 | 可行或最优通量、必需反应候选、预测生长 |
| 常用术语 | FBA：通量平衡；FVA：通量变异范围；objective：目标函数 |
| 代表工具 | COBRApy；COBRA Toolbox；CarveMe |
| 前提、QC与证据边界 | 最优解依赖目标函数；模型通量不是直接测得真实细胞通量 |
| 代表来源与延伸阅读 | [cobra](../../references/index.md#cobra) |


<a id="m110"></a>
## M110 质谱成像与空间代谢组

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 进阶专题 |
| 处理目的 | 定位代谢物/脂质的空间分布 |
| 基本原理 | 在组织坐标逐点采集质谱并配准组织图像 |
| 输入数据 / 上游实验 | MALDI/DESI成像谱、坐标、组织图像与标准 |
| 核心处理 | 峰处理；归一；空间聚类；注释；组织配准 |
| 可以得到的结果 | m/z空间图、区域特异代谢特征 |
| 常用术语 | MSI：质谱成像；imzML：成像谱格式；ion suppression：离子抑制 |
| 代表工具 | Cardinal；SCiLS；METASPACE |
| 前提、QC与证据边界 | 像素信号受基质/离子抑制影响；m/z定位不保证化学物唯一鉴定 |
| 代表来源与延伸阅读 | [msdial](../../references/index.md#msdial) · [squidpy](../../references/index.md#squidpy) |


<a id="m111"></a>
## M111 代谢通路、富集与联合组学解释

| 项目 | 内容 |
| --- | --- |
| 学习层级 | 方向核心 |
| 处理目的 | 提出过程重塑与关键酶假设 |
| 基本原理 | 将代谢特征映射反应网络并和RNA/蛋白整合 |
| 输入数据 / 上游实验 | 已注释代谢物、表达/蛋白及反应数据库 |
| 核心处理 | ID映射；背景定义；富集；网络和因子分析 |
| 可以得到的结果 | 通路候选、跨层次一致/不一致证据 |
| 常用术语 | metabolite set：代谢物集合；pathway topology：通路拓扑 |
| 代表工具 | MetaboAnalyst；MOFA；COBRApy |
| 前提、QC与证据边界 | 代谢物浓度是池大小不是反应速率；未知峰注释不确定性会传播 |
| 代表来源与延伸阅读 | [msdial](../../references/index.md#msdial) · [mofa](../../references/index.md#mofa) · [cobra](../../references/index.md#cobra) |
