# 实验读出

理解原始信号、归一化分母、对照与质量控制，才能判断后续计算结果。以下29类条目用于理解读出，不是实验操作规程；代表来源与延伸阅读的适用范围见 [参考资料说明](../references/index.md)。

## E001 qPCR / RT-qPCR

| 项目 | 内容 |
| --- | --- |
| 读出原理 | 扩增曲线达到阈值的循环数与起始模板量相关；RNA先逆转录 |
| 输入 / 原始观测 | DNA或RNA/cDNA；荧光扩增曲线；内参 |
| 可以得到的结果 | Cq、相对表达或标准曲线校准的拷贝量 |
| 应理解的对照与QC | 无模板、无逆转录、引物效率、稳定内参、独立生物重复 |
| 证据边界 | 2^-ΔΔCq需扩增效率等前提；技术复孔不是生物重复 |
| 代表来源与延伸阅读 | [rnaseq](../references/index.md#rnaseq) · [stats](../references/index.md#stats) |

## E002 数字PCR / ddPCR

| 项目 | 内容 |
| --- | --- |
| 读出原理 | 把样本分隔为很多反应，按阳性比例用Poisson模型估计分子数 |
| 输入 / 原始观测 | 分区阳性/阴性信号、分区体积与阈值 |
| 可以得到的结果 | 模板拷贝浓度、置信区间、等位比例 |
| 应理解的对照与QC | 空白、阈值、分区数、抑制与标准样本 |
| 证据边界 | 绝对定量仍依赖体积/阈值与有效分区；DNA量不等于细胞量 |
| 代表来源与延伸阅读 | [stats](../references/index.md#stats) · [sarek](../references/index.md#sarek) |
