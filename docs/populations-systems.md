# 群体、进化、生态、神经与系统建模

[知识导航](../atlas/index.md) · [生物学基础](biology-basics.md) · [模型与统计](statistics-basics.md) · [百科与依据](../references/wikipedia.md#systems)

计算生物学不只研究分子和单细胞。它也研究遗传历史、微生物群落、物种分布、神经活动和系统行为。跨领域共同的方法不是同一套软件，而是先明确对象、观测过程和想回答的问题。

## 1. 先分清个体、种群、群落和生态系统

**个体**是一个生物体；**种群（population）**通常指一定范围内同种生物的集合；**群落（community）**包含共同出现的多个物种；**生态系统（ecosystem）**还包括它们与非生物环境的相互作用。不同研究会对范围作具体定义。[百科入口](../references/wikipedia.md#systems)

测一个样本的DNA、调查一个样地的物种、记录一只动物的行为，都涉及取样。每条序列、每次拍摄或每个时间点，不自动成为独立个体。共同祖先、相同环境和重复观测都可能产生相关性。[统计基础](statistics-basics.md)

## 2. 进化与共同祖先：序列为什么可以帮助重建历史？

**进化**涉及群体遗传特征随世代改变。突变产生变化，选择、遗传漂变、迁移和重组等过程改变版本的分布。**自然选择**涉及遗传差异与繁殖贡献之间的关系；**遗传漂变**强调有限群体中的随机变化，不等于测序随机错误。[Population genetics](../references/wikipedia.md#systems)

**同源（homology）**指共同祖先关系；**序列相似性**是可测量的相似程度，可以帮助推断同源，但不是同一个概念。**直系同源ortholog**与物种分化相关，**旁系同源paralog**与基因复制相关。相似序列未必具有完全相同的功能。[系统发育方法](../atlas/domains/20-evolution.md)、[IQ-TREE](../references/index.md#iqtree)

## 3. 系统发育树怎样读？

**系统发育（phylogenetics）**用数据和演化模型研究共同历史。树的**末端tip**通常是采样对象，**内部节点**表达祖先关系，**枝branch**连接分化过程。**根root**提供树的方向；没有根的树不能直接按左右位置读出谁先出现。

**枝长**可能表示替换数量或时间，要看模型及校准。**支持度**衡量某种数据和方法下对分组的支持，不是“所有历史都已确定的概率”。基因树与物种树可能不同，因为复制、基因流等过程会使不同序列具有不同历史。[IQ-TREE](../references/index.md#iqtree)、[HyPhy](../references/index.md#hyphy)

分析通常从可比较的序列位置出发，再进行模型选择、树推断、支持和敏感性检查。比对错误也会传递到树上；漂亮的分叉图不能代替对输入和假设的理解。

## 4. 群体遗传：频率、关联与历史各是什么？

**等位频率**表示一个版本在所讨论群体中的比例；**基因型频率**表示相应基因型的比例；**单倍型**描述同一染色体上的版本组合；**LD，连锁不平衡**描述不同位点版本的非随机共同出现。

GWAS研究遗传版本与性状关联，人口史模型估计有效群体大小、分化或迁移等过程，选择分析考察相对特定中性模型的偏离。这些任务可能使用相似变异数据，却回答不同问题。[PLINK](../references/index.md#plink)、[tskit](../references/index.md#tskit)、[HyPhy](../references/index.md#hyphy)

**有效群体大小**是模型中影响漂变等行为的参数，不简单等于实际个体计数。**祖源**的含义依赖采样、参考和模型，不应把一种统计聚类当作绝对、永久的群体边界。[进化条目](../atlas/domains/20-evolution.md)

古DNA还带来降解、化学损伤、污染和低覆盖。泛基因组则扩大参考可表示的序列。它们分别改变观测过程和参考范围，不自动给出唯一的历史或功能结论。[Nature N01](../references/nature-papers.md#n01)

## 5. 微生物组：有哪些、能做什么、正在做什么？

**微生物群（microbiota）**侧重相关微生物，**微生物组（microbiome）**在不同语境中可能包含其遗传信息及环境背景，应看研究定义。**宏基因组学（metagenomics）**从混合样本的遗传物质研究群落，未必先分离培养每一种生物。[百科概念](../references/wikipedia.md#systems)

| 数据或任务 | 原理与结果 | 分析意义 |
| --- | --- | --- |
| 16S、18S、ITS等标记扩增子 | 测定用于分类比较的标记区域 | 概括可检出的标记类型和组成 |
| ASV推断 | 在误差模型下辨别扩增子序列变体 | 尽可能区分真实序列与测序误差 |
| shotgun宏基因组 | 广泛读取混合遗传物质 | 物种/菌株、基因和功能潜力 |
| 组装与分箱 | 拼接片段并按证据归入候选基因组 | 获得宏基因组组装基因组MAG |
| 宏转录组/宏蛋白组 | 测量群落RNA或蛋白 | 增加表达活动层证据 |
| 代谢和群落模型 | 结合化学读出、环境与网络 | 推断交换及过程关系 |

**ASV**是扩增子序列变体，不保证一条ASV对应唯一物种；**MAG**是从混合数据重建的基因组候选，需要评估完整性和污染。标记序列测量不能直接提供完整菌株基因组；检测到某功能基因也不等于当时该过程正在执行。[DADA2](../references/index.md#dada)、[MetaPhlAn 4](../references/nature-papers.md#n06)

## 6. 多样性、物种分布与检测过程

**丰富度richness**关心有多少种，**均匀度evenness**关心各类数量是否均衡；不同多样性指标对稀有或优势群体的权重不同。**α多样性**常描述样本内多样性，**β多样性**描述样本间组成差异。它们不自动代表生态系统健康或某种功能强弱。[Biodiversity](../references/wikipedia.md#systems)、[vegan](../references/index.md#vegan)

**物种分布模型（SDM）**把出现记录与环境变量联系，预测模型定义下的出现相关量或适生性。遥感记录反射、温度或几何代理，环境DNA记录相关遗传物质。它们都需要解释测量与生物数量之间的联系。[biomod2](../references/index.md#biomod)

**占据模型**把“是否真的出现”和“是否被检测”分开。一个最简单的示意中，z=1表示占据，p表示检测概率，y表示这次是否检出：

$$y\mid z\sim\mathrm{Bernoulli}(zp).$$

Bernoulli表示0/1结果。这里假设无假阳性；当y=0时，既可能z=0，也可能z=1但没检出。重复调查和适合的检测模型可以增加区分信息。更复杂研究还要考虑误报、迁移、时间和空间结构。[生态方法](../atlas/domains/21-ecology-plants.md)

## 7. 植物与农业：环境和倍性不能省略

田间性状可能受到遗传背景、环境和两者互作影响。**G×E**是基因型与环境互作：不同基因型在不同环境下的表现差异并不相同。**QTL定位**寻找相关遗传区域；**基因组选择**利用广泛遗传信息预测目标性状，预测能力与作用机制是不同目标。

**多倍体**具有多套染色体。拷贝、亚基因组和剂量会影响变异及表达归属；相似序列不能任意当成同一个基因，也不能直接套用二倍体唯一比对的假设。表型图像、光谱和点云增加形态及环境读出，但还需要地面测量或其他验证解释其含义。[植物与农业方法](../atlas/domains/21-ecology-plants.md)

## 8. 神经系统：电活动、连接和行为是三类对象

**神经元**是神经系统的重要细胞类型；**膜电位**描述细胞膜两侧的电势差；**动作电位（action potential）**是快速的电信号变化；**突触（synapse）**是细胞之间传递信号的专门连接结构。电极、活动成像和结构成像对这些对象提供不同信息。[Action potential](../references/wikipedia.md#systems)

| 方法 | 记录或计算什么 | 主要结果 |
| --- | --- | --- |
| 膜片钳 | 膜电流或电压 | 电生理性质和响应 |
| 多电极与spike sorting | 从混合波形中分离活动来源 | unit及脉冲时间，需质量判断 |
| 钙/电压成像 | 活动相关荧光随时间变化 | 信号轨迹、事件或推断活动 |
| 连续电子显微重建 | 细胞和突触的结构 | 连接图和几何 |
| 姿态与行为分析 | 视频关键点和时序特征 | 轨迹、姿态和行为状态 |
| 编码与解码 | 统计联系刺激、活动和行为 | 可解释或可预测的关系 |

**unit**是算法分离的活动来源候选，不保证每个都完全对应一个真实神经元。钙信号是活动的代理，连接图是结构证据，行为预测是统计任务。Kilosort、CaImAn和DeepLabCut分别处于不同任务位置。[Kilosort](../references/index.md#kilosort)、[CaImAn](../references/index.md#caiman)、[DeepLabCut](../references/index.md#dlc)

跨模态配准让活动和结构对应到相同对象，MICrONS展示了这种整合的价值；但结构边、功能强度与行为因果作用仍应分开。[Nature N11](../references/nature-papers.md#n11)

## 9. 机制模型：从规则预测现象，也从数据约束规则

**常微分方程（ODE）**表达量随时间的连续变化；**随机模型**表达离散事件和概率；**反应—扩散模型**把局部反应与空间运输结合；**基于个体/代理的模型**为细胞或个体设定行为规则；**网络模型**表达对象间的关系。[COPASI](../references/index.md#copasi)、[生物物理方法](../atlas/domains/22-biophysics-modeling.md)

给定规则和参数计算结果叫**模拟**；从数据估计参数叫**拟合**；询问不同参数是否能由当前数据分开叫**可辨识性分析**；询问某参数变化对结果影响多大叫**灵敏度分析**。

一个模型可能很好地拟合数据，但另一个机制也可能拟合得同样好。因此模型的价值不仅是画出相似曲线，还包括预测未用于拟合的观测，指出哪些额外测量可以区分解释。

## 10. 发育与合成生物学：图案和功能怎样形成？

细胞增殖、分化、迁移、信号、反馈与力学共同影响组织形成。定量发育研究这些过程如何产生时空结构；合成生物学则尝试将元件和规则组织为可检验的系统。一个画出的网络或计算生成的结构，还需要连接到实验可观察量。[定量发育与合成生物学](../atlas/domains/25-development-synthetic-biology.md)

**正反馈**能在某些条件下放大变化，**负反馈**能在某些条件下抵消变化；具体是否形成稳定状态、振荡或其他行为，还取决于参数、时间延迟和整体结构，不能只看箭头正负。

## 11. 药理与转化：剂量不等于暴露，暴露不等于作用

**药代动力学（PK）**研究体内相关物质浓度怎样随时间变化，涉及吸收、分布、代谢和排泄；**药效动力学（PD）**研究暴露和作用之间的关系。给定剂量并不意味着每个对象都获得同样暴露，分子作用也不自动等于个体结局。[PK与PD概念](../references/wikipedia.md#systems)

剂量响应曲线、靶点结合、生存分析和多变量预测分别解决不同问题。生存数据中的删失表示观察受限，不等于事件不会发生；体外细胞结果要外推到个体，需要额外证据。本知识库解释分析概念，不提供诊疗或用药方案。[转化与药理方法](../atlas/domains/24-translational-pharmacology.md)、[统计基础](statistics-basics.md)

## 这些领域怎样联系起来？

遗传数据约束共同历史，环境数据约束外部条件，成像约束位置与结构，时间观测约束过程，干预约束改变后的响应。不同领域可以共享统计思想，但必须尊重各自的对象、单位和观测机制。
