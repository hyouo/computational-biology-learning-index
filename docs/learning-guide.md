# 测量、数据、模型与生物学解释

[知识导航](../atlas/index.md) · [生物学概念](biology-basics.md) · [统计概念](statistics-basics.md) · [技术联系](technique-relations.md)

生物学研究通常从一个问题开始：哪些东西不同？这种变化由什么过程产生？改变一个因素，会发生什么？计算分析的作用，是把实验记录整理成与这些问题有关的证据。这篇先用同一个问题串起实验、数据与解释，再补充一般原理。

## 1. 一个问题，为什么会产生多种数据？

假设我们想研究：“受到某种刺激后，细胞为什么分泌更多蛋白A？”这是教学情景，不是对某个具体实验的描述。

可以测RNA，了解产生蛋白所用的模板是否改变；可以测细胞内和培养液中的蛋白，了解数量及分布；可以观察细胞数量，区分是每个细胞分泌更多，还是分泌细胞更多；还可以测时间变化，了解顺序。不同技术增加的是不同信息，不能把它们都当作“再证明一次表达升高”。[分子调控](molecular-regulation.md)、[蛋白与功能](structure-function.md)

这就是**科学问题、实验、分析任务和软件**的区别：“为何分泌更多”是问题，RNA-seq是测量RNA的一类实验，差异表达是比较任务，DESeq2是其中一种统计实现。[DESeq2](../references/index.md#deseq)

## 2. 生物对象怎样变成数字？

可以先记住下面的关系：

> 生物对象 → 取样与实验处理 → 仪器信号 → 对象识别和定量 → 可分析的数据。

“原始数据”总是相对于分析入口而言。测序仪可能先记录电流或图像，碱基识别后得到序列文件；对从FASTQ开始的分析而言，FASTQ是原始输入，但它不是最底层仪器信号。显微镜记录像素强度，分割后才得到细胞面积；质谱记录离子信息，鉴定后才得到蛋白表。[测量原理](instruments-and-data.md)、[HTSlib](../references/index.md#hts)、[CellProfiler](../references/index.md#cellprof)、[MaxQuant](../references/index.md#maxquant)

这条链里，每一步都可能改变能看见的范围。例如，某类RNA未被建库方案捕获，后面的软件不会自动恢复它；两个细胞被错误分成一个对象，后面的细胞统计也会受到影响。理解数据必须包括这些上游条件。

## 3. 先问“这个数是什么”，再问“它大不大”

| 数据里的数 | 首先表示什么 | 进一步解释需要什么 |
| --- | --- | --- |
| RNA计数 | 归属到基因或转录本的read/UMI等数量 | 建库、归属、样本尺度和重复信息 |
| 染色质区域计数 | 某实验在该区域记录的片段数 | 究竟是可及性、抗体富集还是其他实验 |
| 图像强度 | 像素或对象内检测到的信号 | 标记、曝光、背景、线性范围和尺度 |
| 质谱峰 | 指定质荷比和时间附近的离子信号 | 分子鉴定、加合物、碎片、校准 |
| 三维密度值 | 重建模型中的空间密度 | 原始约束、局部分辨率和模型验证 |
| 模型预测分数 | 给定训练和输入后的计算输出 | 分数目标、校准、误差和适用范围 |

这些不是抽象的“生物学活性分数”。例如，ATAC的开放区域和CUT&Tag的靶标富集测的是不同性质；预测结构的置信度和实验密度也不是同一种量。[ATAC](../references/index.md#atacpaper)、[CUT&Tag](../references/index.md#cuttag)、[AlphaFold 3](../references/nature-papers.md#n07)

## 4. 数据处理到底增加了什么？

**识别与重建**回答“对象是什么、在哪里”，例如比对、谱图鉴定和图像分割。**归一化**使某类量在明确意义下可比较。**降维与分组**把复杂模式展示出来。**统计比较**估计条件差异及不确定性。**注释与整合**把结果连接到基因、细胞、通路或其他知识。每一步的问题不同。[计算方法基础](computation-basics.md)

使用同一个数据对象，不代表里面的数值可以互换。例如，原始计数、对数变换后的矩阵和UMAP坐标可能存放在同一单细胞文件中，却分别用于不同计算。用于显示的表示，不必适合计数模型。[Scanpy](../references/index.md#scanpy)、[DESeq2](../references/index.md#deseq)

**数据库和参考也参与解释。**把一段序列命名为某物种，依赖参考中有什么；把基因连接到通路，依赖注释覆盖。MetaPhlAn 4把组装发现的微生物纳入参考，说明参考范围会改变能够识别的对象。[Nature论文N06](../references/nature-papers.md#n06)

## 5. 两个最值得先理解的数字问题

### 分母：比例下降，不一定数量下降

教学例子：样本甲中A有10个、其他分子共10个，A占50%；样本乙中A仍有10个、其他分子共90个，A占10%。A的相对比例下降，但绝对数量没有变化。

这不是说相对数据没有价值，而是说它回答“占多少”而非自动回答“总共有多少”。比较细胞组成、微生物相对丰度或相对分子量时，都要知道分母。[统计基础](statistics-basics.md)

### 层级：测得更多细胞，不等于更多独立个体

一只动物中的许多细胞帮助认识个体内部差异；来自多只动物的观测帮助判断个体之间的变化。若研究处理对动物的影响，不能把同一动物的每个细胞都当成独立动物。pseudobulk按个体和细胞类型汇总，或使用适配的层级模型，是将问题与实验单位对应的方法。[muscat](https://pmc.ncbi.nlm.nih.gov/articles/PMC7705760/)

## 6. 统计模型不是把软件名称换成公式

模型表达“观测为什么会这样变化”的假设。对RNA计数，模型可以区分样本的总体测量规模、基因的条件效应和计数随机变化。对图像，模型也可能涉及分割误差、重复视野和个体层级。选择模型的起点是数据生成过程，而非哪个软件最流行。

<details>
<summary>进一步看：RNA计数模型中的符号</summary>

DESeq2使用的一类计数表达可概括为：

$$K_{gi}\sim\mathrm{NB}(\mu_{gi},\alpha_g),\quad \mu_{gi}=s_iq_{gi},\quad \log q_{gi}=X_i\beta_g.$$

这里g表示基因，i表示样本；K是观察计数；NB表示负二项分布，用于描述计数及其变异；μ是期望计数；α描述离散程度；s是样本尺度；q是模型中的表达参数；X记录条件和协变量；β记录相应效应。它并不把q自动校准成细胞内绝对分子浓度。

这一表示把三个问题分开：读得更多、表达不同、随机变化更大。具体设计、系数和检验要参照[DESeq2原始研究和文档](../references/wikipedia.md#core-sources)。完全重合的批次与处理条件不会因写入公式就被成功区分。

## 7. 哪些结果能回答哪些问题？

| 问题 | 结果可以怎样表述 | 下一步还可了解什么 |
| --- | --- | --- |
| 有什么、多少、在哪里？ | 检测、定量、重建了某对象 | 检测范围、误差、漏检与归属 |
| 哪些量一起变化？ | 存在差异、共变或关联 | 是否有共同原因、组成或技术因素 |
| 未观察的对象可能怎样？ | 模型预测了结构、标签或响应 | 独立数据、适用对象和校准 |
| 改变某因素会怎样？ | 在指定干预和条件下观察到效应 | 干预是否成立、直接/间接作用、外推范围 |

这些问题没有统一的“高低级”排序。描述一张可信的组织图谱本身可以回答重要问题；机制解释则需要辨别哪些过程产生了现象。关键是对结果使用与其证据一致的语言。[技术关系](technique-relations.md)

## 8. 回到分泌蛋白的例子：怎样逐步形成解释？

如果RNA增加，只说明模板相关量改变；如果培养液蛋白也增加，又增加了分泌结果的证据；如果独立测得细胞数不变，便减少了一种“只是细胞更多”的解释；如果干预候选调控因素后响应改变，就得到该条件下的干预效应。进一步区分直接作用、细胞损伤、全局分泌变化等，还需要相应读出。

这个例子不是建议所有项目都做相同实验套餐，而是说明：**有价值的下一项技术，应提供当前解释缺少的信息。**增加很多共享同一输入和假设的预测，不等于增加同样数量的独立证据。
