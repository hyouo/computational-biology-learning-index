# 测量、数据、模型与生物学解释

[知识导航](../atlas/index.md) · [技术关系](technique-relations.md) · [术语](../glossary/index.md)

## 生物学问题、测量技术和分析方法不是同一层东西

“某个基因是否改变细胞状态”是生物学问题；RNA-seq是获得RNA相关观测的一类实验；差异表达是比较条件的分析任务；DESeq2是该任务的一种统计实现。把这四层混成一列软件名，会丢失方法为什么存在、结果意味着什么。DESeq2的输入要求和设计矩阵正说明：实验设计是模型的一部分，不是数据分析之外的备注。[DESeq2](../references/index.md#deseq)

同理，冷冻电镜是测量与重建体系，三维分类是计算任务，原子模型是输出之一；分子动力学则在给定体系和力场下模拟运动。它们都涉及结构，但并不产生相同类型的证据。[CryoSPARC](../references/index.md#cryo)、[GROMACS](../references/index.md#md)

## 从生物系统到数字：观测模型

可以用一个示意关系表示数据的来源：

> 生物状态 + 取样方式 + 实验条件 → 仪器信号 → 识别与定量 → 可分析的数据对象。

这个关系不是说所有误差都能写成一个相加的噪声项。检测限、选择性捕获、错误归属和样本混合会以不同方式改变数据；有些信息在取样时已丢失，不能靠下游算法完整恢复。[DESeq2](../references/index.md#deseq)、[Cell2location](../references/index.md#cell2loc)

| 数据对象 | 数字首先代表什么 | 还不能直接说成什么 |
| --- | --- | --- |
| RNA计数矩阵 | 某个定量定义下归属到特征的读段或UMI数 | 无偏、绝对的细胞内分子总数 |
| 可及性peak矩阵 | 在候选区域记录的可及性相关片段 | 特定TF已经结合、增强子已被功能验证 |
| 空间分子坐标和细胞掩膜 | 检出的分子位置及计算得到的对象归属 | 所有分子被完整观测、每个细胞边界都正确 |
| 质谱特征表 | 某个m/z、保留时间或迁移率特征的信号 | 唯一化合物身份及未经校准的绝对浓度 |
| 三维密度图 | 实验信号经重建得到的空间密度 | 每处都已被唯一解释的原子模型 |
| 模型预测轨道 | 从输入及训练得到的关系推断的信号 | 同一样本新做了一次实验的结果 |

这些区别分别可在[CUT&Tag](../references/index.md#cuttag)、[空间脑图谱](../references/nature-papers.md#n04)、[单细胞代谢组](../references/nature-papers.md#n16)、[CryoSPARC](../references/index.md#cryo)和[AlphaGenome](../references/nature-papers.md#n14)的具体输入输出中看到。表格是跨技术概括，不意味着一种实验具备其他实验的测量能力。

## 处理步骤为什么会改变解释

**识别与重建**把信号变成对象：base calling识别碱基，谱图匹配识别肽段，分割识别细胞，电镜重建产生密度。对象识别错误会传递到后续统计；图像分割因此不只是“画出好看的边界”。[CellSAM](../references/nature-papers.md#n13)、[MaxQuant](../references/index.md#maxquant)

**归一化**定义可比较的尺度；**变换与降维**改变用于比较的表示；**推断模型**在假设下回答具体问题。归一化矩阵、用于可视化的嵌入和用于差异检验的输入不必相同，也不能因为都放在一个数据对象中就互换。[DESeq2](../references/index.md#deseq)、[Scanpy](../references/index.md#scanpy)

**注释**把计算特征映射到已知概念，例如基因、细胞类型、通路或物种。数据库缺失和命名体系会影响能识别什么；MetaPhlAn 4把组装发现的微生物纳入参考，就是“参考知识改变可观察范围”的例子。[N06](../references/nature-papers.md#n06)

## 一个公式说明：计数不等于待解释的生物效应

RNA计数的一类模型可写为：

$$K_{gs}\sim\mathrm{NB}(\mu_{gs},\alpha_g),\quad \mu_{gs}=s_s q_{gs},\quad \log q_{gs}=X_s\beta_g.$$

这里g为基因，s为样本，K为观察计数，s_s为样本尺度因子，q为模型中的表达参数，X包含条件及协变量，alpha表示离散程度。统计模型试图区分尺度、条件和随机变化。q并不是已经校准的绝对分子浓度；模型也无法从完全混杂的设计中凭空分离处理和批次。[DESeq2](../references/index.md#deseq)

方法的核心不只是得到P值，还包括比较对象、效应大小及不确定性。大量同时检验时需要控制错误发现；FDR不是单个基因“为假的概率”。[统计方法](../atlas/domains/01-statistics.md)、[statsmodels](../references/index.md#stats)

## 分母与层级：两类普遍的误读

**相对量的分母。**假设两个样本中A分子的绝对数量均为10，而其他分子总数由10变成90；A的比例会从50%变成10%，但A本身没有减少。这是一个算术示例，不是真实实验数据。它说明比例变化不能直接替代绝对数量变化。RNA相对定量、细胞组成和微生物相对丰度都要先解释分母。[DESeq2](../references/index.md#deseq)、[MetaPhlAn](../references/index.md#metaphlan)

**独立性的层级。**细胞嵌套于个体、图像嵌套于组织、重复时间点嵌套于同一个体。同一组内很多观测有助于刻画个体内部，但不自动增加个体间比较的独立重复。单细胞差异状态可以使用个体×细胞类型汇总或适配的层级模型；不能仅凭细胞数量判断组间证据强度。[muscat](../references/index.md#muscat)

## 四种问题分别需要什么结果

| 问题 | 合适的结果语言 | 解释边界 |
| --- | --- | --- |
| 有什么、在哪里、是多少？ | 重建、鉴定、定量及误差 | 受检测、参考、分割和定量定义影响 |
| 哪些量共同变化？ | 关联、差异、模块、空间富集 | 可能存在共同原因、组成变化和技术因素 |
| 未观测的对象会怎样？ | 预测及其适用范围 | 依赖训练信息和验证分布，不自动揭示机制 |
| 改变一个因素会怎样？ | 给定干预、条件和读出下的效应 | 需区分直接作用、间接作用及实际干预是否成立 |

这些不是一条“低级到高级”的统一排名。结构重建可以独立回答重要问题；因果判断也不限定只能来自敲除。关键是问题与证据匹配，而不是把所有描述研究都写成机制研究。[AlphaFold 3](../references/nature-papers.md#n07)、[Perturb-tracing](../references/nature-papers.md#n10)、[因果推断相关方法](../atlas/domains/04-population-genetics.md)

## 知识库中的三类来源

百科入口用于识别概念、别名和相邻主题；原始研究用于核对具体技术的测量与推断关系；官方文档用于核对实现和输入输出。百科不承担全部技术论证，近年论文也不会让较早的基本原理失效。正文为独立归纳，不复制百科或论文全文。[来源入口](../references/index.md)、[近年论文](../references/nature-papers.md)
