# 基因组、染色质、RNA与调控

[知识导航](../atlas/index.md) · [基因与表达的基础概念](biology-basics.md) · [测序原理](instruments-and-data.md) · [百科与依据](../references/wikipedia.md#molecular)

这一层研究两件相关但不同的事：遗传信息是什么，以及细胞怎样使用这些信息。可以把DNA序列、染色质、RNA和蛋白看作同一系统的不同观察角度，但不能把其中一个角度等同于全部功能。

## 1. DNA、RNA和蛋白分别告诉我们什么？

DNA序列帮助理解遗传信息及其变化；RNA提供哪些信息被转录、怎样加工和积累的观察；蛋白则提供执行层的组成与状态。中心法则说明序列信息的转移，不表示蛋白不能反馈调节转录，也不意味着RNA数量必然与蛋白活性成比例。[Crick原文](../references/index.md#crick)、[蛋白与功能](structure-function.md)

同样一份RNA数量可以由合成和降解共同决定。因此，问“RNA多不多”和“转录快不快”，需要不同数据。先明确想知道的是数量、结构、位置还是速率，才能选分析任务。

## 2. 基因组分析：先认识序列，再解释差异

**全基因组测序（WGS）**关注广泛的基因组序列；**外显子测序（WES）**富集外显子相关区域；**靶向panel**围绕预先选定区域。覆盖的区域不同，不能把没有测到的区域写成“没有变异”。[基因组流程](../references/index.md#sarek)

| 计算任务 | 用通俗语言理解 | 主要输入 → 输出 |
| --- | --- | --- |
| 比对 | 这段read可能来自参考的哪里？ | reads与参考 → 比对位置及质量 |
| 组装 | 这些碎片能拼成什么序列？ | reads → 较长连续序列及组装图 |
| 变异检测 | 哪些差异不太像测量错误？ | 比对证据 → 候选变异和基因型 |
| 分相 | 多个变异分别位于哪条染色体？ | 变异、read或家系信息 → 单倍型 |
| 注释 | 差异落在哪里，已知什么相关信息？ | 变异与注释库 → 功能背景和候选影响 |

**SNV**是单个核苷酸的变化，**Indel**是插入或缺失；**结构变异（SV）**涉及更大范围的连接或结构改变；**拷贝数变异（CNV）**涉及某区域份数。**VAF**是变异等位在所定义读段证据中的比例，不等于携带变异的细胞比例；肿瘤混合、拷贝数和倍性会改变它。[HTSlib](../references/index.md#hts)、[变异方法](../atlas/domains/03-genomics.md)

短片段在重复区域可能有多个放置位置。长读段和单倍型组装增加跨越这些区域的证据；**泛基因组**将多个个体的序列路径纳入参考，增加对不同遗传背景的表示。它改变分析能看见什么，但不会直接告诉我们某变异的功能。[hifiasm](../references/index.md#hifiasm)、[Nature N01](../references/nature-papers.md#n01)

## 3. DNA的包装为什么也是信息？

DNA与相关蛋白组成**染色质**，其中核小体等结构影响DNA的组织与接近条件。**启动子**参与转录起始，**增强子**能在特定背景下调节转录，**转录因子（TF）**参与识别和调节。DNA元件属于序列层，因子占据属于分子作用层，可及性属于接近条件层。[基础定义](biology-basics.md)、[NHGRI：Chromatin](https://www.genome.gov/genetics-glossary/Chromatin)

这些层次之所以要分开，是因为“门开着”“有人站在门口”“屋里发生了工作”不是同一事实。这个类比只帮助区分可及性、占据和功能输出，不表示每个基因都只有一个开关。

## 4. 几种染色质技术分别观察什么？

| 技术 | 原理和输入 | 得到的结果及意义 |
| --- | --- | --- |
| ATAC-seq、DNase-seq | 用酶进入或切割DNA的差异形成片段 | 可接近区域及其变化 |
| ChIP-seq | 用抗体富集与目标相关的染色质，再读序 | 指定蛋白或修饰相关的富集区域 |
| CUT&RUN、CUT&Tag | 抗体将切割或转座活动引向目标附近 | 靶标相关片段及空间分布 |
| DNA甲基化测量 | 利用化学、酶或直接读序信号辨别碱基修饰 | 位点或区域的修饰比例与差异 |
| motif分析 | 从序列寻找相似的偏好模式 | 可能参与识别的因子候选 |
| Hi-C、Micro-C | 记录空间邻近区域产生的连接片段 | 区域间接触频率矩阵 |

**峰（peak）**是相对背景富集的区域；**peak calling**是在实验和统计假设下识别这些区域。不同抗体、测量与背景会给出不同含义，不能看到一个峰就统称“基因被激活”。[ATAC原始研究](../references/index.md#atacpaper)、[CUT&Tag原始研究](../references/index.md#cuttag)、[MEME Suite](../references/index.md#meme)

**Input对照**通常帮助描述未按同样靶标富集的背景；**spike-in**是在设计中加入外部参考。它们服务于不同问题，不是可随意互换的“对照样本”。具体使用取决于实验方案。[染色质分析条目](../atlas/domains/06-epigenomics.md)

## 5. 三维基因组与增强子—基因联系

DNA在一维序列上相隔很远的区域，在细胞核中可能接近。接触矩阵的一行和一列对应基因组区间，格子里的值描述它们在特定实验及处理下的接触信号。分析可概括为区室、边界或局部接触结构，分别对应不同尺度的空间组织。

接触次数不是直接的欧氏距离，也不自动等于调控强度。增强子可能面对多个候选基因，需要结合位置、活性、接触、共同变化或干预结果解释。**增强子—靶基因链接**必须说明是根据哪种证据建立的。[表观与三维基因组](../atlas/domains/06-epigenomics.md)、[SCENIC+](../references/nature-papers.md#n03)

**MPRA（大规模并行报告分析）**把大量候选序列连接到报告输出；**内源扰动**则在原有基因组背景中改变候选区域。前者强调序列在报告体系中的能力，后者强调原有环境中的功能；环境不同可能产生不同结果。将扰动与三维读出结合，又可以研究空间组织对干预的响应。[扰动方法](../atlas/domains/11-perturbation.md)、[Perturb-tracing](../references/nature-papers.md#n10)

## 6. RNA-seq怎样回答“哪些RNA改变”？

在常见流程中，read先归属到基因或转录本，形成数量表，再结合样本条件进行比较。**counts**是计数；**TPM**是按长度和总体量处理的一类相对转录本丰度表示；**log2FC**描述模型比较中的倍数变化；**调整P值**用于多重检验下的判断。它们不是同一种单位。[DESeq2](../references/index.md#deseq)、[统计基础](statistics-basics.md)

总体RNA数据通常混合许多细胞。某基因在组织里升高，可能来自同类细胞内部变化，也可能来自高表达该基因的细胞变多。因此差异表达表首先回答指定样本设计下的RNA相关变化，后面再解释其来源。[细胞与组成](cells-space-time.md)

## 7. 总量、异构体、端点和结构：不同RNA任务

| 想知道什么 | 为什么普通基因总量表不够？ | 可以增加的技术或分析 |
| --- | --- | --- |
| 使用了哪一种转录本？ | 同一基因可以有多个结构版本 | 长读长RNA、异构体重建 |
| 哪个外显子更常被保留？ | 总量不包含连接的使用比例 | 剪接连接与差异剪接分析 |
| 从哪里开始、在哪里结束？ | 起止位置变化未必改变总量 | CAGE、RAMPAGE、3′端和APA分析 |
| 有哪些小RNA？ | 常规建库不一定有效覆盖它们 | 小RNA测序及专用注释 |
| 是否出现融合或RNA编辑？ | 需要异常连接或碱基差异的证据 | 嵌合read、匹配DNA与专用过滤 |
| 哪些区域被核糖体使用？ | RNA存在不等于正在翻译 | Ribo-seq，核糖体足迹测量 |
| RNA与哪些蛋白接触？ | 表达相关不等于分子接触 | CLIP、eCLIP、iCLIP |
| RNA怎样配对或修饰？ | 序列和数量不能直接确定化学状态 | DMS/SHAPE、修饰探测与相应模型 |

**PSI**是某种定义下的剪接包含比例；**DTU**是差异转录本使用；**APA**是可变多聚腺苷化，涉及不同的RNA末端使用。长读段结构与剪接比例的分析分别可参照[IsoQuant](../references/nature-papers.md#n02)和[rMATS](../references/index.md#rmats)。

**RBP**是RNA结合蛋白；CLIP相关实验提供接触信息，但接触是否改变RNA命运还需功能证据。结构探测提供反应性约束，富集型修饰实验可能只定位候选区域，不能一概当成单碱基绝对修饰比例。[eCLIP](../references/index.md#eclip)、[DMS-MaPseq](../references/index.md#dms)、[RNA方法](../atlas/domains/05-transcriptomics.md)

## 8. 数量与速率：为什么需要时间和标记？

可以将RNA数量理解为同时受产生和消失控制的存量。**新生RNA**是在某个观测窗口中新产生的RNA；**代谢标记**通过标记信息区分新旧分子。不同测量还可能观察延伸中的转录或暂停，而不是最终积累量。[SLAM-seq](../references/index.md#slam)

最简单的示意模型为：

$$\frac{dR}{dt}=k_{syn}-k_{deg}R.$$

R是RNA数量，t是时间，左边表示数量变化速度；k_syn是产生速度，k_deg是每单位时间的降解比例参数。在该一阶模型达到稳态时，R=k_syn/k_deg。相同数量可以对应不同的合成与降解组合。真实体系还可能涉及加工、运输和反馈，所以这个公式是入门模型，不是所有RNA过程的完整描述。[COPASI](../references/index.md#copasi)

**半衰期**是相应衰减模型下减为一半所需的时间；**稳态**是数量不随时间改变，不等于内部没有产生和消耗。

## 9. 从遗传关联到分子调控的解释

GWAS关联序列版本与性状；分子QTL关联序列版本与表达、剪接或蛋白等量。精细定位帮助从一起遗传的候选变异中缩小范围；共定位考察两个关联信号是否兼容共享来源。[SuSiE](../references/index.md#susie)、[coloc](../references/index.md#coloc)

序列预测模型是另一类信息：它把未做实验的序列变化映射为可能的读出变化。必须先理解模型预测的是调控轨道、序列概率还是特定功能，不把所有分数统一叫作“致病性”。[AlphaGenome](../references/nature-papers.md#n14)、[Evo 2](../references/nature-papers.md#n15)

这条主线最后连接到[细胞状态](cells-space-time.md)和[蛋白功能](structure-function.md)：序列与调控提供机制线索，而实际状态还需要其他层次的观测。
