# 内容维护

## 目录约定

`atlas/domains/` 保存方法家族卡片；`experiments/` 保存测量原理和对照；`glossary/` 保存带语境的术语；`learning-notes/` 保存自己的阅读、复现与案例记录。README 只保留仓库用途和项目结构。

方法沿用稳定的 `M001` 等编号，实验沿用 `E001` 等编号。扩展内容时不要重排已有编号。保留方法锚点，更新领域导航以及相关术语链接。

## 新增一份笔记

复制 `templates/` 中对应文件到 `learning-notes/`，使用清晰的文件名，例如 `learning-notes/methods/M035-bulk-rnaseq.md`。模板中的“待填写”只是占位，不代表已经有数据或完成复现。

每次更新记录资料来源、阅读日期、软件版本、输入数据出处和仍未解决的问题。未核验的信息明确标注，不把预测输出写成直接实验事实。

## 数据与隐私

仓库以文字、脚本和小型公开示例为主。不要提交访问凭证、个人敏感信息、受限人类数据或大型原始实验文件。数据优先记录公开 accession、版本、校验和及获取方式。`.gitignore` 只提供常见提醒，不能替代提交前检查。

## 本地校验

需要 Python 3.10 或更新版本，不需要第三方依赖。在仓库根目录运行：

```bash
python scripts/validate.py
```

脚本检查方法编号是否重复、领域导航是否覆盖方法文件、Markdown 内部链接及锚点是否存在，以及来源记录是否为有效 JSON。校验通过不代表科学内容已经核实；它不会联网检查外部链接，也不会重新执行任何分析。
