# 蛋白、结构、相互作用与代谢

[知识导航](../atlas/index.md) · [蛋白与酶的基础](biology-basics.md) · [质谱和结构测量](instruments-and-data.md) · [百科与依据](../references/wikipedia.md#measurement)

知道一个基因的序列或RNA数量，还不能完全知道它产生的分子怎样工作。蛋白是否存在、在哪里、怎样折叠、与谁结合、是否有活性，是不同问题；代谢物数量和反应速度又是另外两个问题。本篇将这些量分开，再说明技术如何把它们连接起来。

## 1. 从一条氨基酸链到功能分子

蛋白由氨基酸连接组成。序列是一维排列；局部折叠形成螺旋、折叠片等结构；整条链具有三维组织；多条链或其他分子还可组装成复合物。**构象（conformation）**描述其中一种空间状态，蛋白可能在多个状态之间变化。[蛋白基础](biology-basics.md)、[Protein structure](../references/wikipedia.md#biology)

**残基（residue）**指链中某个氨基酸单元；**结构域（domain）**是相对独立的结构或功能部分；**结合位点**与识别伙伴有关；**活性位点**与催化过程有关。它们并不保证一一对应。蛋白被修饰、降解、运输或与伙伴结合时，功能也可能改变。

因此测到蛋白增加，只增加了数量方面的信息；要说明活性增加，还需针对功能的读出。

## 2. 质谱为什么经常先读肽段，而不是整条蛋白？

常见**bottom-up蛋白质组**把蛋白转成较短的肽段，质谱检测离子和碎片，再由计算识别可能的肽序列。**肽（peptide）**是较短的氨基酸链；**PSM（peptide-spectrum match）**是一次谱与候选肽的匹配。多个蛋白可能共有相同肽，因此“识别了肽”还需要进一步推断来自哪些蛋白。[MaxQuant](../references/index.md#maxquant)

**质荷比m/z**、**保留时间RT**、碎片组合提供不同识别信息。**谱库**记录参考谱，**序列数据库**提供候选序列。数据库范围、碎片匹配和错误控制都会影响鉴定结果。一个未检出的蛋白可能是不存在，也可能因覆盖或检测条件没有被识别。

## 3. 采集方式、定量方式和功能读出要分开

| 类别 | 主要做什么 | 结果如何理解 |
| --- | --- | --- |
| DDA，数据依赖采集 | 根据前体信号等规则选择进一步采集对象 | 得到被选中对象的碎片信息 |
| DIA，数据非依赖采集 | 按窗口等方案系统采集混合碎片 | 需要计算分离不同来源的贡献 |
| LFQ，无标记定量 | 利用可比较的肽/蛋白信号进行定量 | 通常是相对丰度，不自动是浓度 |
| SILAC、TMT等标记方案 | 用同位素或化学标签组织样本比较 | 需要理解标签、混合和定量信号 |
| PRM、SRM等靶向测量 | 围绕选定肽和相关离子进行检测 | 可结合标准进行有针对性的定量 |
| PTM分析 | 识别翻译后修饰及其位点 | 修饰信号、总量和占比需要区分 |

DDA/DIA首先是采集设计；LFQ/TMT等涉及比较和定量；PTM则是想观察的蛋白状态。不能把这些词都排成互斥的“软件选择”。[DIA-NN](../references/index.md#diann)、[MSstats](../references/index.md#msstats)、[蛋白质组方法](../atlas/domains/13-proteomics.md)

蛋白、肽和PSM是不同汇总层级。某一层的FDR控制不能直接当作另一层的保证。修饰肽增加也可能来自蛋白总量增加，需要适当参照才知道修饰程度是否改变。

## 4. “相互作用”到底是哪一种关系？

**共同富集**：从样本中富集一个诱饵分子时，其他分子一起被保留，例如Co-IP或AP-MS。它们可能同处一个复合物，也可能通过中间伙伴连接。

**邻近标记**：诱饵附近的分子被局部标记，再检测富集，例如BioID、TurboID或APEX相关方法。它提供时空邻域的证据，不直接等于两者相互接触。

**直接结合测量**：在明确体系中观察结合行为，例如SPR、BLI、MST或ITC等；不同技术分别利用表面光学变化、运动或热等读出，需要相应模型解释。[TurboID](../references/index.md#turbo)、[实验读出](../experiments/index.md)

共同富集、空间邻近、直接结合、改变功能可以互补，但不应统一缩写成“证明互作”。界面预测还属于结构假设，不能代替定量结合测量。[AlphaFold 3](../references/nature-papers.md#n07)

## 5. 实验结构是怎样得到的？

| 技术 | 原始约束 | 计算增加的信息 |
| --- | --- | --- |
| 冷冻电镜单颗粒 | 许多不同方向的颗粒投影 | 分类、取向估计和三维密度 |
| 冷冻电子断层cryo-ET | 同一区域的倾转序列 | 原位三维体，及相似局部结构的平均 |
| X射线晶体学 | 晶体的衍射强度与相位约束 | 电子密度、原子位置和精修模型 |
| NMR，核磁共振 | 位移、耦合、距离与动态相关谱信息 | 结构集合和运动约束 |
| SAXS/SANS，小角散射 | 不同散射尺度的曲线 | 整体尺寸、形状和相容构象 |

**密度图**是空间信号的重建，**原子模型**是对该信号及其他信息的结构解释。高质量数据可以支持更精细的解释，但并非每个区域都有相同分辨率。[CryoSPARC](../references/index.md#cryo)、[RELION](../references/index.md#relion)、[Phenix](../references/index.md#phenix)、[BioXTAS RAW](../references/index.md#saxs)

**CTF**描述电镜成像的对比度传递；**half-map**来自相对独立的数据部分；**FSC**比较两幅图在不同空间频率上的一致性。晶体学中的**Rfree**则使用留出反射评价模型。它们都与验证有关，但不是同一个指标。[结构方法](../atlas/domains/15-structural-biology.md)

## 6. 预测、对接、模拟和设计，各自回答什么？

**结构预测**从序列、分子实体和训练知识生成空间坐标假设。**pLDDT**描述局部结构预测可信度，**PAE**描述相对位置误差预测；它们不是实验密度，也不是结合亲和力。[AlphaFold 3](../references/nature-papers.md#n07)

**分子对接（docking）**寻找受体和配体的相对姿势并用近似函数评分。**分子动力学（MD）**在力场和边界条件下推进运动，得到轨迹；**力场（force field）**近似描述原子相互作用；**RMSD**量化选定对象对齐后的坐标差异，不是通用功能正确性指标。[AutoDock Vina](../references/index.md#vina)、[GROMACS](../references/index.md#md)

**自由能计算**针对明确状态估计热力学差异；**增强采样**帮助探索普通模拟难以跨越的状态；**QM/MM**把部分区域用量子描述、其他区域用分子力学描述，以研究涉及电子变化等过程。是否采样充分、质子化和化学状态是否合适，都会影响解释。[计算化学方法](../atlas/domains/16-computational-chemistry.md)

**设计**从目标约束反向提出候选序列或结构。计算候选还需要表达、折叠、结合或功能方面的验证。多个计算共享同一初始结构时，不应自动当成彼此独立的验证。[RFdiffusion](../references/nature-papers.md#n05)

## 7. 亲和力、反应速率和抑制浓度有什么不同？

**亲和力**描述指定条件下的结合倾向，**结合/解离速率**描述来去有多快，**催化速率**描述转化过程。它们针对不同问题。

在简单的一对一平衡结合P+L↔PL中：

$$K_D=\frac{[P][L]}{[PL]}.$$

P是蛋白，L是配体，PL是复合物，方括号表示平衡时的相应浓度。在同一模型和可比较条件下，较低Kd对应较强结合倾向。结合是否产生功能后果仍要另外测量。

在简化酶反应E+S↔ES→E+P和Michaelis–Menten条件下：

$$v=\frac{V_{max}[S]}{K_m+[S]}.$$

这里E是酶、S是底物、P在本反应中表示产物；v是反应速度，Vmax是模型最大速率，Km是达到其一半时的底物浓度参数。Km还取决于结合、解离与催化过程，通常不能直接等同于Kd。**IC50**则是特定测定下产生50%抑制的浓度，依赖测定条件。[酶与动力学概念](../references/wikipedia.md#biology)、[COPASI](../references/index.md#copasi)

注意：不同公式中的字母可能代表不同对象，不能仅按字母记住生物学含义。

## 8. 代谢组：先识别化学对象，再比较数量

**代谢物**是代谢过程中的相关小分子；**脂质组**聚焦脂质；**非靶向分析**尝试较广地发现特征；**靶向分析**围绕预定分子进行检测和定量。一个质谱特征可能对应同位素、加合物或碎片，同一分子也可能贡献多个特征。

因此，特征发现、分子注释和标准确认是不同工作。相同质量也可能对应不同结构，需要结合保留时间、碎片和标准品等信息。峰面积不是未经校准的绝对浓度。[MS-DIAL](../references/index.md#msdial)、[代谢组方法](../atlas/domains/14-metabolomics.md)

空间质谱增加位置，单细胞代谢组增加细胞尺度；这些拓展观察范围，但没有取消鉴定和定量的不确定性。[Nature N16](../references/nature-papers.md#n16)

## 9. 浓度与通量：存量和流量

**浓度**是单位体积中的量；**反应通量（flux）**是按指定单位归一后，每单位时间通过某反应的量。某个代谢物积累，可能因为产生增加，也可能因为消耗减少。单个时点浓度不能唯一确定流量。

**稳定同位素示踪**追踪标记原子进入不同分子的模式；**同位素分布**提供来源和路径线索；结合时间、摄取/分泌和反应网络后，**代谢通量分析（MFA）**估计相应流量。[代谢方法](../atlas/domains/14-metabolomics.md)

**通量平衡分析（FBA）**则从化学计量和边界条件构造约束，再按目标求解。简化质量守恒为：

$$\frac{dc}{dt}=Sv;\qquad \text{稳态时 }Sv=0.$$

c是代谢物浓度向量，v是反应通量向量，S记录每个反应消耗和产生多少各类分子。稳态不是所有反应停止，而是各代谢物净变化为零。**FVA**考察约束下的通量范围；最优解不保证就是实际细胞的唯一状态。[COBRApy](../references/index.md#cobra)

## 10. 将分子层重新放回细胞环境

序列影响可形成的分子，结构限制接触几何，物理和化学约束反应，定位和伙伴改变环境。多个读出共同帮助区分机制，但其中任何一个都不自动解释全部表型。
