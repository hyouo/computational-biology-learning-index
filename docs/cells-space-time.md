# 细胞身份、状态、空间、时间与扰动

[知识导航](../atlas/index.md) · [细胞与分子基础](biology-basics.md) · [条码、成像和流式](instruments-and-data.md) · [百科与依据](../references/wikipedia.md#cells)

组织由不同细胞及其环境构成。研究组织变化时，至少有六个问题：有哪些细胞？它们处于什么状态？各有多少？在哪里？怎样变化？从哪里来？单细胞、空间、时间和谱系技术分别增加其中的不同信息。

## 1. 细胞类型、细胞状态和细胞簇

**细胞类型（cell type）**通常概括相对稳定的身份特征；**细胞状态（cell state）**描述刺激、活动、周期或环境相关变化。两者的界限依赖研究问题，并非总有绝对划分。**细胞簇（cluster）**则是算法根据当前数据和相似性得到的组，不自动等于一种真实细胞类型。[单细胞概念](../references/wikipedia.md#cells)、[Scanpy](../references/index.md#scanpy)

例如，同一种细胞可以处于分裂与非分裂状态；同一状态程序也可能出现在多个类型。**marker（标记）**是帮助识别类型或状态的特征，通常要联合多个特征和背景判断，不能只看单个基因。

一个细胞还具有形态、蛋白、代谢、染色质和空间位置。RNA向量只是其中一部分，因此“表达相似”不是“全部生物学性质相同”。[WNN](../references/index.md#wnn)

## 2. 单细胞RNA数据从哪里来？

常见方法将细胞或细胞核分到捕获单位，用条码标记来源，再把RNA相关序列归属到基因。**scRNA-seq**是单细胞RNA测序，**snRNA-seq**是单核RNA测序。细胞核和完整细胞能够观察的RNA范围不同。

**细胞条码**区分捕获单位；**UMI**帮助区分原始分子与扩增副本；**双细胞（doublet）**指同一单位混入两个细胞等情形；**环境RNA（ambient RNA）**来自捕获单位周围的游离RNA。空液滴不代表一定没有RNA信号，有条码也不代表一定是单个有效细胞。[测量解释](instruments-and-data.md)、[Scanpy](../references/index.md#scanpy)

得到矩阵后，常见指标包括每个细胞的检测基因数、计数、线粒体相关读出等。它们帮助识别异常，但阈值要结合组织和方案，不能把一种数据的经验规则照搬到所有细胞。

## 3. 从矩阵到细胞图谱，计算分别做什么？

| 处理 | 提供的信息 | 需要理解的术语 |
| --- | --- | --- |
| 质量控制 | 哪些记录适合后续问题 | QC、双细胞、环境RNA |
| 归一化与特征选择 | 可比较的尺度和关注特征 | 高变基因HVG、计数与变换层 |
| 表示与近邻图 | 对象在指定特征空间的关系 | PCA、近邻、距离 |
| 聚类 | 哪些对象形成相似群体 | 簇、分辨参数 |
| 注释与参考映射 | 群体可能对应什么身份 | marker、参考、标签置信度 |
| 批次整合 | 不同数据中哪些结构可以对应 | 共享状态、批次与真实差异 |

UMAP常用于展示关系；它的二维坐标不是细胞在组织中的实际位置。整合后不同批次混得均匀，不自动说明结果更正确，因为真实的处理差异也可能被过度消除。[计算基础](computation-basics.md)、[scvi-tools](../references/index.md#scvi)

## 4. “细胞变了”和“细胞变多了”怎样区分？

教学例子：组织中有甲、乙两类细胞。每个甲细胞都表达较高的基因A。处理后A的组织平均信号升高，至少可以由两种情况解释：甲细胞内部表达增加，或者甲细胞在样本中的贡献增加。

**差异状态分析**比较同类细胞在不同条件中的读出；**差异丰度分析**比较各类细胞或邻域的组成。它们都要保留独立个体或样本信息。把每个细胞当成一个独立动物，会夸大重复数量。[muscat](https://pmc.ncbi.nlm.nih.gov/articles/PMC7705760/)

**pseudobulk**按个体与细胞类型汇总，再进行样本层比较。它不是把所有样本混成唯一一份。**解卷积**则用参考和模型解释混合信号。混合权重可能反映RNA产量和捕获贡献，不一定直接等于细胞数比例。[Cell2location](../references/index.md#cell2loc)

## 5. 多组学：同一细胞的不同侧面怎样连接？

**scATAC-seq**观察单细胞可及性；**CITE-seq**等方法将RNA与抗体标签读出联系；其他共测方法连接RNA、染色质或更多信息。每种模态的特征和噪声不同：抗体panel未必覆盖所有蛋白，可及性也不是直接RNA计数。[WNN](../references/index.md#wnn)、[单细胞方法](../atlas/domains/07-single-cell.md)

同一细胞的配对观测提供明确对应；不同细胞或不同切片的数据需要模型建立对应。**联合嵌入**描述共同表示，**潜因子**概括变化程序，**补全**预测没有测到的模态，**调控网络**提出机制关系。它们分别回答不同问题。[MOFA](../references/index.md#mofa)、[SCENIC+](../references/nature-papers.md#n03)

## 6. 空间测量究竟增加了什么？

分离细胞便于观察个体差异，但往往丢失原位置。空间方法把分子与位置联系起来，帮助理解组织区域、邻居和局部环境。

| 方式 | 怎样记录位置 | 常见结果 |
| --- | --- | --- |
| 捕获式空间RNA | RNA与空间条码关联 | 位置×基因的矩阵 |
| 成像式空间RNA | 探针或原位读序在图像中定位分子 | 分子坐标及细胞归属 |
| 多重空间蛋白成像 | 多种标记在同一组织位置检测 | 通道信号、细胞和蛋白分布 |
| 图像引导取样加质谱 | 图像定义区域或对象，再分析分子 | 形态与蛋白结果的对应 |

**spot**是捕获或记录位置，不保证只有一个细胞；**panel**是预先选定的测量对象集合；**分割掩膜**定义细胞边界；**配准**将图像或切片对齐。每种方式都要保留其分辨率和对象定义。[空间脑图谱](../references/nature-papers.md#n04)、[Deep Visual Proteomics](../references/index.md#dvp)

一个基因不在成像panel中，模型预测出的空间值不能称为新增实测。细胞边界出错也会改变分子归属和邻域分析。[Nicheformer](../references/nature-papers.md#n12)、[CellSAM](../references/nature-papers.md#n13)

## 7. 邻域、生态位与细胞通信

**邻域**是在给定距离或连接规则下的周围对象；**生态位**强调局部环境和其他细胞共同提供的条件；**空间域**是分子或形态特征形成的区域。它们不是只靠一张彩色区域图就能互换的标签。

**配体**可与受体结合；**受体**帮助将某些外部信号连接到细胞响应。配体—受体计算把表达和已知分子关系结合，寻找候选发送端与接收端。空间信息进一步约束哪些对象可能相遇，下游响应和干预再帮助判断是否有功能作用。[CellChat](../references/index.md#cellchat)、[LIANA+](../references/nature-papers.md#n09)

因此，表达兼容、空间邻近、信号激活和功能效应分别增加不同证据。共同环境也可能让两个群体一起变化。

## 8. 时间、方向、命运与祖先

| 方法或概念 | 简单解释 | 与其他概念的区别 |
| --- | --- | --- |
| 真实时间序列 | 多个明确时间点的观测 | 不一定追踪同一个细胞 |
| 拟时序 | 在状态相似性上安排相对顺序 | 不是实际分钟或天数 |
| RNA velocity | 用RNA加工相关信息估计局部变化方向 | 依赖动力学，不是实测细胞位移 |
| 命运概率 | 状态转移模型中的终末趋向 | 不是已经观测到的后代 |
| 谱系记录 | 用可遗传标记推断共同来源 | 不等于当前状态相似 |
| 活细胞追踪 | 随时间匹配同一个对象 | 仍可能错配或漏掉分裂 |

**克隆（clone）**强调共同来源，**细胞簇**强调当前相似。二者可能一致，也可能不一致。**分支**可以是状态图中的分支，也可以是真实谱系分叉，阅读时要看证据来自哪一类数据。[RNA velocity](../references/index.md#velocity)、[CellRank 2](../references/nature-papers.md#n08)、[动态与谱系](../atlas/domains/08-dynamics-lineage.md)

## 9. 扰动：主动改变系统后观察什么？

**敲除（knockout，KO）**目标是破坏某基因功能；**敲低（knockdown）**降低相关产物；**过表达**增加产物；**CRISPRi/a**分别利用相应系统抑制或激活转录。**guide RNA**引导靶向，但检测到guide不等于预期编辑或功能变化已经充分发生。[扰动方法](../atlas/domains/11-perturbation.md)

池化筛选将许多扰动放在同一实验中，根据身份标签区分。guide丰度变化反映携带相应扰动细胞在选择中的相对变化；**Perturb-seq**把身份与RNA状态连接；光学筛选连接图像；Perturb-tracing连接三维染色质。分析意义取决于干预后的读出，而不只是用了哪一种编辑工具。[MAGeCK](../references/index.md#mageck)、[scPerturb](../references/index.md#scperturb)、[Nature N10](../references/nature-papers.md#n10)

**回补（rescue）**尝试恢复相关因素并观察是否恢复表型；**组合扰动**帮助了解两个因素是否存在相互依赖。它们需要解释实际干预、剂量、背景及替代过程，不能把恢复现象自动缩写成唯一直接机制。

## 10. 免疫、肿瘤与发育怎样使用这些信息？

**免疫组库**研究TCR、BCR等受体序列的集合，帮助连接受体身份、克隆扩增和细胞状态。相似克隆或受体序列可提供线索，但不能独自确定识别什么抗原。[Scirpy](../references/index.md#scirpy)、[Immcantation](../references/index.md#immcant)

**肿瘤克隆**强调遗传共同来源，**亚克隆**是其中进一步分化的群体；肿瘤样本还混有非肿瘤细胞。遗传克隆比例需要考虑纯度、倍性和拷贝数，RNA状态簇不能直接替代DNA证据。[免疫与肿瘤](../atlas/domains/12-immunity-cancer.md)

**发育与分化**研究细胞怎样形成不同身份和组织；**类器官**等模型提供观察相关过程的体系，但并非完整个体的无差别替代。状态、时间、谱系、空间和力学一起约束对组织形成的解释。[定量发育](../atlas/domains/25-development-synthetic-biology.md)、[系统建模](populations-systems.md)

这一层最重要的区分是：**细胞是什么、现在怎样、位于哪里、可能怎样变化，以及来自哪里，分别需要相应的信息。**
