# 生物学基础：从细胞到基因、蛋白和表型

[知识导航](../atlas/index.md) · [实验怎样产生数据](instruments-and-data.md) · [基础概念来源](../references/wikipedia.md#biology)

这篇从生物学对象本身开始。看到一种分析技术时，先认识它研究的东西，再理解为什么会产生那种数据。文中序列和数量例子用于解释概念，不是某项真实实验的结果。

## 1. 细胞、组织和个体：研究对象有不同尺度

**细胞（cell）**是细胞生命的基本结构和功能单位。细胞膜将内部与外界分开，内部发生物质合成、分解、运输和信息调节。**组织（tissue）**由细胞及周围细胞外成分共同组成；器官包含协同工作的多种组织。一个细胞的变化，不等于整个组织或个体都发生同样变化。

**真核细胞**具有膜包围的细胞核，动物、植物和真菌属于真核生物。细菌和古菌属于**原核生物**，没有同样的膜包围细胞核，但不是没有DNA。核糖体参与蛋白合成，原核和真核细胞都有；线粒体、叶绿体等细胞器承担不同功能，并非每类细胞都具有相同配置。病毒不是细胞，其增殖依赖宿主细胞相关过程。[百科概念：细胞](../references/wikipedia.md#biology)

这些区别影响取样：取整个组织、分离完整细胞或只取细胞核，得到的分子集合不同。“一个样本”可能指一只动物、一份组织或一个捕获单位，必须看实验定义。

## 2. 先认识经常被测量的分子

| 分子 | 组成与主要作用 | 数据分析通常问什么 |
| --- | --- | --- |
| DNA，脱氧核糖核酸 | 由核苷酸连接形成，序列保存可传递的遗传信息 | 序列是什么？哪里不同？有多少拷贝？ |
| RNA，核糖核酸 | 可传递编码信息，也可承担结构、催化和调控功能 | 有哪些？多少？怎样加工和降解？ |
| 蛋白质，protein | 氨基酸连接成链，折叠或组装形成结构 | 在哪里？结合什么？是否有活性？ |
| 代谢物，metabolite | 代谢中的底物、中间物和产物等小分子 | 有哪些化合物？浓度多少？经过什么过程？ |

脂质参与膜结构、能量储存和信号；糖类参与能源和结构，也能连接在蛋白或脂质上影响其性质。生物学并不只有DNA、RNA和蛋白三类对象。[蛋白、酶和代谢概念](../references/wikipedia.md#biology)

## 3. DNA字母、方向和坐标是什么意思？

DNA常用A、C、G、T表示四种碱基。**序列（sequence）**是碱基的排列；两条互补DNA链中，常见配对为A与T、C与G。RNA通常用U代替T。**5′和3′**表示核酸链的化学方向，不是前五个或后三个碱基；序列通常按5′到3′书写。

下面是人为构造的比较：

```text
位置（从1开始）  1 2 3 4 5 6
参考序列        A C G T A C
样本序列        A C A T A C
```

第3个位置，参考为G，样本为A。**bp（base pair，碱基对）**常描述双链DNA长度；**nt（nucleotide，核苷酸）**描述核苷酸数量。**参考基因组**提供定位和比较基准，不是唯一正确或健康的序列。文件中的坐标还可能从0开始，不能与此处从1开始的教学编号混用。[NHGRI术语](https://www.genome.gov/genetics-glossary)、[数据坐标示例](../data-formats/index.md)

## 4. 基因、染色体、基因组和等位基因

**染色体（chromosome）**是遗传物质的组织单位。**基因组（genome）**是所讨论对象的整套遗传信息，还要明确是否包含线粒体、叶绿体等基因组。**基因（gene）**可以先理解为与产生功能性RNA或蛋白相关的遗传信息单位，不是每个基因都编码蛋白；精确边界也可能依赖定义和研究语境。[NHGRI：Gene](https://www.genome.gov/genetics-glossary/Gene)

同一位点的不同序列版本称**等位基因（allele）**。**基因型（genotype）**描述个体携带的版本；**变异（variant）**描述相对比较基准的差异。变异不自动有害，也可能只在特定条件下表现出影响。

**单倍体、二倍体和多倍体**描述染色体组数。在典型二倍体位点，两份版本相同称纯合，不同称杂合；实际数据还要考虑性染色体、拷贝数和混合样本。**单倍型（haplotype）**是同一染色体上的版本组合，**分相（phasing）**是确定不同变异分别位于哪条染色体。知道“有哪些版本”和知道“它们怎样组合”是不同信息。[NHGRI术语表](https://www.genome.gov/genetics-glossary)、[基因组方法](../atlas/domains/03-genomics.md)

## 5. 基因表达：如何产生功能产物？

**转录（transcription）**以DNA为模板产生RNA。**翻译（translation）**在核糖体上根据mRNA中的密码子排列合成氨基酸链。RNA提供模板，并不是RNA分子本身直接变成了蛋白。[NHGRI：转录](https://www.genome.gov/genetics-glossary/Transcription)、[翻译](https://www.genome.gov/genetics-glossary/Translation)

**mRNA**是信使RNA；**rRNA**是核糖体RNA，参与核糖体结构与功能；**tRNA**是转运RNA，在翻译中连接密码子识别和氨基酸携带。**非编码RNA**不以编码蛋白为主要产物，不等于没有功能。

中心法则关注**序列信息怎样转移**。常见路径是DNA→RNA→蛋白，但不表示所有生物作用只能单向传递。RNA→DNA的逆转录不推翻这一原始含义；蛋白调节转录也不是把蛋白序列逆向翻译成DNA。[Crick原文](../references/index.md#crick)

## 6. 一个基因为何会有多个转录本？

许多真核基因的初始RNA经历加工。**外显子（exon）**是保留在相应成熟转录本中的部分；**内含子（intron）**是在剪接中被去除的部分。外显子不全等于蛋白编码区：成熟mRNA还可能包含不被翻译的**UTR（untranslated region，非翻译区）**。

不同的起始、外显子组合和末端加工，可以形成不同**转录本异构体（transcript isoform）**。例如：

```text
异构体一：外显子A — 外显子B — 外显子C
异构体二：外显子A — 外显子C
```

两个样本中某基因的RNA总量相同，异构体比例仍可能不同。“差异表达”和“剪接或异构体使用分析”因此回答不同问题。[剪接概念](../references/wikipedia.md#molecular)、[IsoQuant](../references/nature-papers.md#n02)、[rMATS](../references/index.md#rmats)

## 7. 染色质与调控：相近DNA如何产生不同状态？

**染色质（chromatin）**是DNA与相关蛋白形成的复合组织。DNA围绕组蛋白形成核小体，是其组织形式之一；包装与可接近条件都影响后续过程。[NHGRI：Chromatin](https://www.genome.gov/genetics-glossary/Chromatin)

**启动子（promoter）**与转录起始有关；**增强子（enhancer）**可在特定背景下影响转录；**转录因子（transcription factor，TF）**是参与调节转录的蛋白。**顺式cis**主要涉及同一DNA分子上元件的作用关系，**反式trans**涉及可作用于其他位点的调控分子。

**表观遗传**讨论不改变DNA序列的功能状态变化，其中一些能够维持或传递。不能把任何一次染色质变化都叫作跨代遗传。可及性、特定蛋白占据和DNA修饰是不同性质，分别需要相应读出。[概念入口](../references/wikipedia.md#molecular)、[分子调控与实验](molecular-regulation.md)

## 8. 蛋白数量、结构、结合和活性

蛋白的氨基酸序列是一维排列，结构描述空间组织，**构象**是可能的空间状态；**结构域**是相对独立的结构或功能部分；多个分子还可形成**复合物**。一张结构图不意味着蛋白在所有环境下都固定在该姿势。

**酶（enzyme）**催化反应，多数是蛋白，也存在具有催化作用的RNA。酶通过改变反应路径加快速率，并不会任意改变反应的平衡位置。**底物（substrate）**在反应中被转化为产物；**配体（ligand）**与目标结合，但不一定被转化。[蛋白与酶概念](../references/wikipedia.md#biology)

“蛋白更多”“结合更紧”“反应更快”分别需要数量、结合和动力学方面的信息。RNA计数不能独自回答它们，详见[蛋白、结构与代谢](structure-function.md)。

## 9. 信号、通路、反馈、标记与表型

**受体（receptor）**识别某些信号；**信号通路（signaling pathway）**描述信号怎样通过分子过程影响下游。**磷酸化**是加上磷酸基团的一类修饰，作用依分子和位点而变，不能一律翻译成激活。**反馈（feedback）**是下游反过来影响上游，可使系统形成不同动态。[调控与网络](../atlas/domains/10-multi-omics-networks.md)

**表型（phenotype）**是可观察或测量的性质，如细胞形状、生长、酶活性或个体性状。它取决于遗传背景、环境和过程之间的关系，不是某个基因的简单标签。**标记（marker）**帮助识别对象或状态，不一定负责造成该状态。[NHGRI术语](https://www.genome.gov/genetics-glossary)、[细胞身份与状态](cells-space-time.md)

## 10. “组学”是什么，又不是什么？

“组学”强调系统地研究一类对象的集合，不保证将全部对象无遗漏地测到。

| 名称 | 主要对象 | 提供的观察角度 |
| --- | --- | --- |
| 基因组学，genomics | DNA序列及变化 | 遗传信息与结构 |
| 转录组学，transcriptomics | RNA集合 | 表达、加工和动态 |
| 表观组学，epigenomics | 染色质、DNA修饰等 | 信息使用的相关环境 |
| 蛋白质组学，proteomics | 蛋白及其状态 | 分子执行层的组成 |
| 代谢组学，metabolomics | 代谢相关小分子 | 化学状态 |
| 多组学，multi-omics | 两个或多个分子层次 | 跨层次关系，不是自动证明因果 |

“单细胞”强调测量到细胞尺度，“空间”强调保留位置，“时间序列”增加采样时间，“扰动”主动改变系统。它们可以与不同组学组合，并不是互斥的学科。[百科入口](../references/wikipedia.md#cells)
