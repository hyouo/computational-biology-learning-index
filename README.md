# Computational Biology Learning Index

这个仓库用于帮助我自己和可能需要的人，从数据本身理解生物学。

## 项目结构

```text
computational-biology-learning-index/
├── README.md
├── docs/                       # 知识正文：基础概念、原理与技术联系
│   ├── biology-basics.md       # 细胞、基因、RNA、蛋白与表型
│   ├── instruments-and-data.md # 实验和仪器怎样产生数据
│   ├── statistics-basics.md    # 数据、重复、差异与不确定性
│   ├── computation-basics.md   # 比对、降维、聚类、富集与模型
│   ├── learning-guide.md       # 测量、数据、模型与生物学解释
│   ├── technique-relations.md  # 技术之间的逻辑与分析意义
│   ├── molecular-regulation.md # 基因组、染色质、RNA与调控
│   ├── cells-space-time.md     # 细胞状态、空间、动态与扰动
│   ├── structure-function.md   # 蛋白、结构、相互作用与代谢
│   └── populations-systems.md  # 进化、生态、神经与系统建模
├── atlas/
│   ├── index.md                # 基础概念与25个领域的知识导航
│   └── domains/                # 技术与方法条目
├── experiments/
│   └── index.md                # 实验读出、对照与解释边界
├── data-formats/
│   └── index.md                # 数据对象、文件字段、维度与单位
├── glossary/
│   └── index.md                # 术语及其生物学语境
└── references/
    ├── index.md                # 原始研究与官方文档
    ├── wikipedia.md            # 百科概念及基础来源对应
    └── nature-papers.md        # Nature系列论文中的技术与证据
```
